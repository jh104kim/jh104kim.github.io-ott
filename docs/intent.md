## 1. 제품 의도 (Product Intent)

**Screen Intelligence Agent는 한국에서 실제로 볼 수 있는 재미있고 화제성 높은 영화·드라마를, 사용자의 시청 이력과 취향에 맞춰 빠르게 찾아주는 개인 추천 에이전트다.**

사용자는 자연어로 주제·장르·공개 연도를 말한다. 서비스는 여러 글로벌 OTT와 평점 소스를 조사하지만, **기본 추천 목록에는 대한민국에서 구독·합법 무료·유료 대여·구매 또는 현재 극장 상영으로 관람 가능한 작품을 모두 포함**한다. 작품을 고른 뒤에는 시즌별 맥락·품질 추세·스핀오프와 함께 **관련 유튜브 한국어 요약 영상**에 접근할 수 있다.

### 최상위 성공 조건

1. **볼 수 있음:** 한국에서 **구독·무료·대여·구매 또는 국내 극장 상영(영화만)** 중 하나의 합법적 관람 경로가 검증된 작품을 기본 추천 후보에 포함한다. 이용·관람 방식은 명확히 표시하고 추천 점수와 혼동하지 않는다.
2. **볼 만함:** 재미·관객 만족도 **40%**, 실제 대중 인기·화제성 **40%**, 전문가 평가 **10%**, 개인 취향 **10%**로 추천을 설명한다.
3. **안 본 것:** 시청 완료 영화와 시즌을 기본 결과에서 제외한다.
4. **왜 볼지 앎:** 추천 본문은 핵심 설정·인기 이유·시즌 품질 변화·시리즈 관계를 스포일러 없이 설명한다. 단, 사용자가 열람하는 유튜브 전체 요약은 결말을 포함할 수 있다.
5. **곧바로 이동:** 한국의 구독·무료·대여·구매 작품 페이지, 검증된 영화별 극장 예매 링크(있는 경우), 관련 유튜브 요약 영상으로 이동할 수 있다.
6. **언어 지원 투명성:** 한국어 자막·더빙을 확인할 수 있는 경우 표시하고, 미확인·미지원이라는 이유로 국내 시청 가능 작품을 기본 추천에서 제외하지 않는다.
7. **기다림 최소화:** 추천 목록에 필요하지 않은 심층 조사·유튜브 검색은 처음 응답을 막지 않는다.
8. **유형별 순위:** **영화 TOP 10**과 **드라마 TOP 10**을 별도로 산출하며, 서로 다른 유형의 인기도를 강제로 하나의 순위에 섞지 않는다.
9. **나중에 볼 목록:** 추천 카드에서 `찜`한 관심 작품을 사용자별 관심 목록에 저장하고, 다시 조회·해제할 수 있다. **찜은 추천 순위에 영향을 주지 않으며, 해당 작품·추천 시즌의 `봤음` 저장이 성공하면 자동 해제한다.**
10. **실수 복구:** `봤음`을 `되돌리기` 하면 시청 상태뿐 아니라 **그 작업으로 자동 해제된 기존 찜도 복원**한다. 원래 찜하지 않았다면 새로 생성하지 않는다.
11. **신작 누락 방지:** 국내 합법 시청·관람 경로와 공개 연도가 확인된 신작은 평가 데이터가 적더라도 추천 후보에 포함한다. 존재하지 않는 평점을 만들지 않고 **지표별 결측과 평가 신뢰도**를 표시한다.
12. **신규 시즌 진입 장벽 완화:** 과거 시즌 시청 기록이 없거나 `unknown`이어도 요청 연도의 신규 시즌을 추천하고, **시즌 1부터의 시청 순서**를 안내한다. 시청 전 시즌의 주요 반전은 드러내지 않는다.
13. **점수 미산정 신작의 정직한 분리:** 평가 데이터가 전혀 없어 P-GSEI를 산정할 수 없는 신작은 추천에서 누락하지 않고, 영화·드라마 정규 TOP 10 **외부의 `평가 대기 신작` 영역**에 노출한다. 평가 가능한 신작은 신뢰도 표시와 함께 정규 순위에 포함한다.
14. **선행 시즌 시청 경로의 투명성:** 요청 연도 신규 시즌이 국내에서 시청 가능하면, 과거 시즌의 국내 제공이 확인되지 않아도 추천을 유지한다. 이전 시즌마다 `국내 제공 확인` / `국내 미제공 확인` / `국내 제공 미확인`을 구별하며 정주행이 어려운 경우 경고한다.
15. **분야별 빠른 결과:** 영화·드라마는 각자 독립적으로 조사·검증·점수 계산을 끝낸 즉시 해당 분야의 최종 TOP 10을 보여준다. 나머지 분야는 `검색 중`으로 유지한다. 다른 분야의 지연·실패 때문에 완료된 결과를 숨기거나 취소하지 않는다.
16. **연도의 국제적 일관성:** 사용자가 연도를 지정하면 영화는 **세계 최초 공개 연도**, 드라마는 **해당 시즌의 세계 최초 공개 연도**로 필터링한다. 한국 개봉·공개 연도는 별도 표기하고 추천 연도 기준으로 대체하지 않는다.
17. **공개 예정작과 출시작의 명확한 구분:** 검색 연도에 공개가 예정되어 있지만 **조회 시점 아직 실제 공개되지 않은 영화·신규 시즌**은 정규 영화/드라마 TOP 10과 별도의 **`공개 예정작` 영역**에 표시한다. 예정일·한국 관람 경로는 확인된 사실만 제시하고 **공개 전 P-GSEI 및 순위를 산정하지 않는다**. 이미 공개됐으나 평가가 없는 `평가 대기 신작`과 구분한다.
18. **글로벌 신작 조기 발견:** 공식 근거로 전 세계 공개 계획이 확인된 예정작이라면 한국 출시 계획이 미확정이어도 `공개 예정작`에 표시하고 **`한국 공개 미확인`**을 분명하게 표기한다. 미확정 정보를 국내 관람 가능으로 오인시키지 않으며 정규 TOP 10의 한국 시청 가능 조건은 유지한다.
19. **연도 미입력 시 최신작 우선:** 사용자가 공개 연도를 지정하지 않으면 **조회 시점의 현재 연도를 포함한 최근 3개 연도**의 세계 최초 공개 영화·신규 시즌부터 추천한다. 기존 명작을 찾고 싶을 때는 사용자가 **`전체 연도 보기`**로 연도 제한을 해제할 수 있다.
20. **부족하더라도 자동으로 연도를 넓히지 않음:** 기본 연도 범위에서 검증된 영화·드라마가 각각 10개 미만이면 **확인된 작품만 표시**한다. 검색 범위를 과거 연도까지 확대하려면 사용자가 직접 **`전체 연도 보기`**를 선택해야 한다.
21. **주제 적합성을 인기보다 우선:** 정규 TOP 10은 요청한 장르가 이야기의 핵심 소재인 작품으로 제한한다. 간접적으로 유사한 작품은 **`관련 장르 추천`**에만 분리해 소개할 수 있으며, 후보가 부족하더라도 정규 순위에 섞지 않는다.
22. **인접 장르는 요청했을 때만 검색:** `관련 장르 더 보기`를 사용자가 선택한 경우에만 별도 확장 검색한다. 기본 검색은 정규 TOP 10 확인에 집중하고 인접 장르 검색으로 첫 응답을 지연시키지 않는다.
23. **영드·유럽 드라마는 선택형 확장:** 기본 드라마 추천은 미국 드라마를 대상으로 하고, 영국·유럽 작품은 사용자가 `영드·유럽 드라마 더 보기`를 선택했을 때만 추가 검색한다. 미드 추천 수가 10개 미만이어도 자동 확장하지 않는다. 다만 사용자가 처음부터 영드·유럽 드라마를 명시해 요청한 경우에는 해당 요청 범위를 직접 검색한다.
24. **영드·유럽은 독립된 TOP 10:** 확장 검색 결과는 기존 미국 드라마 TOP 10을 변경하지 않고, **`영드·유럽 드라마 TOP 10`** 별도 섹션에서 최대 10작품으로 P-GSEI 순위를 산정한다. 최초 요청부터 영드·유럽 드라마가 명시되었다면 해당 독립 섹션을 직접 생성한다.
25. **계정별 안전한 기록 동기화:** **Google 계정 OAuth 로그인**으로 사용자별 시청 완료 이력·찜 목록을 안전하게 구분하고 PC·스마트폰에서 동일 상태를 확인한다. 서비스가 Google 비밀번호를 직접 수집하거나 저장하지 않는다.
26. **승인된 사용자만 접근:** 최초 배포는 본인과 사전에 승인한 Google 계정만 사용할 수 있다. OAuth 인증 성공만으로 가입·추천 실행·기록 접근 권한을 주지 않으며, 비승인 계정은 접근을 거부한다. 다중 사용자 지원을 위한 계정 분리는 처음부터 유지한다.
27. **초기 운영 부담 최소화:** 관리자가 승인할 Google 계정을 **서비스 외부의 수동 관리 절차**로 등록·철회한다. 초기에는 앱 내 가입 요청·관리자 승인 화면을 만들지 않는다. 승인·철회 결과는 이후 인증된 요청의 접근 통제에 반영한다.
28. **빠른 재검색과 최신성 선택권:** 동일 조건의 검증된 추천 검색 결과는 **최대 24시간 캐시**해 재사용할 수 있다. 결과의 **정보 확인 시점**을 표시하고 **`최신 정보로 다시 검색`** 기능을 제공한다. 국내 OTT·대여·구매 및 극장 상영 상태는 추천 결과 캐시와 별도로 최신성을 검증한다. 캐시가 있어도 사용자별 시청 완료·찜·관심 없음 상태와 접근 권한은 매 요청 시 현재 데이터를 적용한다.
29. **원치 않는 작품 제외:** 추천 카드의 `관심 없음` 표시를 사용자별로 저장하며, 현재 목록과 순위는 유지하고 **다음 신규 검색부터 추천 결과에서 제외**한다. 이 상태는 `봤음`과 구분하여 관리하고 사용자가 해제할 수 있다. **드라마는 특정 시즌만이 아니라 전체 시리즈(기존·향후 시즌)를 제외**하되, 별도 작품인 스핀오프는 자동 제외하지 않는다(D-32 A안).
30. **관심 없음과 찜 상태 자동 정리:** `관심 없음` 저장이 성공하면 **해당 작품의 찜을 자동 해제**하여 관심 목록에서 제거한다. `관심 없음` 해제 시 그 제외 작업으로 해제됐던 **기존 찜만 복원**하고, 이후 사용자가 직접 수정한 찜 상태는 덮어쓰지 않는다(D-33 A안).
31. **시청 후 선택형 개인 평가:** `봤음` 처리한 영화와 드라마 **시즌**에 **1~5점 개인 별점**을 선택적으로 저장·수정할 수 있다. 입력하지 않아도 시청 완료는 정상 저장된다. 축적된 별점은 P-GSEI 중 **개인 취향 10%**의 근거에만 사용하며, 재미·관객 만족도 40% / 인기·화제성 40% / 전문가 평가 10%의 외부 지표 가중치는 변경하지 않는다(D-34 A안).
32. **별점은 시청을 방해하지 않음:** `봤음` 저장 후 현재 추천 카드 안에 `내 별점`(1~5점)을 선택적으로 보여준다. 별점 선택창을 자동으로 띄우지 않으며, 입력·수정·해제가 즉시 가능하다. 별점 저장 실패 시 성공으로 표시하지 않고 추천 카드·순위는 그대로 유지한다(D-35 A안).
33. **시청 완료 취소 시 별점 보존:** `봤음`을 `되돌리기` 하면 기존 개인 별점을 **삭제하지 않고 보존하되 비활성화**한다. 미시청 상태의 별점은 취향 학습에 반영하지 않으며, 같은 영화·시즌을 다시 `봤음`으로 체크하면 이전 별점이 자동 복원된다(D-36 A안).
34. **API 비용의 사전 통제:** 관리자가 정한 **월별 Google Gemini API 예산 상한과 사용자별 유료 검색·호출 제한**을 적용한다. 검색 전에 남은 예산·할당량을 확인하고 초과 예상 신규 호출을 차단한다. 한도 도달 후에도 기존 검증된 캐시 결과 및 시청 기록·찜 조회는 가능하며, 차단 이유를 명확히 안내한다(D-37 A안).
35. **사용자별 일일 제한:** 사용자마다 **하루 동안 실행할 수 있는 유료 검색 수**를 제한하고, 서비스 전체에는 별도의 **월간 Google Gemini API 예산 상한**을 적용한다. 일일 한도가 다음 날 초기화되어도 월 예산이 소진되었다면 신규 유료 호출은 허용하지 않는다(D-38 A안).
36. **요청 중심 검색 횟수 집계:** 사용자 검색 요청 **1건을 일일 유료 검색 1회**로 집계한다. 같은 요청에서 영화·드라마를 병렬 검색해도 1회이며, 사용자가 별도로 요청한 유료 확장 검색·최신 정보 재검색은 각각 1회다. **추가 Google Gemini API 호출이 없는 검증 캐시 조회는 0회**로 집계한다. 실제 내부 Google Gemini API 호출량과 비용은 이 횟수와 별도로 추적한다(D-39 A안).
37. **작품 상세는 기본 무료, AI 심층 분석은 선택형 유료:** 기존 시즌 정보·평점 추세·스핀오프·검증된 유튜브 링크 등 **Google Gemini API 신규 호출이 없는 상세 열람은 0회 차감**한다. 신규 AI 요약·심층 분석은 사용자가 명시적으로 `AI 상세 분석`을 선택했을 때만 실행하며, **실제 신규 유료 분석 요청 1건당 일일 한도 1회**를 차감한다. 분석 시작 전 한도·비용 사용 사실을 표시하고 월 예산 한도를 동일하게 적용한다(D-40 A안).
38. **공통 공개 캐시·개인화 격리:** 인증 및 접근 승인을 통과한 사용자에게는 공개 작품 메타데이터·평점·시즌·OTT/극장 가용성·스핀오프·개인정보 없는 비개인화 AI 분석 캐시를 공유한다. **시청·찜·관심 없음·개인 별점·취향 프로필 및 개인화 추천 결과는 사용자별로 격리**한다. 공통 캐시 적중 시에도 현재 사용자 권한과 개인 필터, 각 정보의 최신성을 재검증하며, 신규 Gemini API 호출이 없으면 유료 검색 횟수는 차감하지 않는다(D-41 A안).
39. **부분 장애에도 정확성 유지(D-42):** 외부 평점·시청처의 일부 수집이 실패해도 **공개 연도·핵심 장르·현재 한국 관람 경로** 등 필수 근거가 검증된 작품만 각 분야의 확정 목록에 표시한다. 미확인 점수·확인 시점을 명시하며 검증되지 않은 작품으로 부족한 순위를 채우지 않는다.
40. **검색 결과 없음도 설명 가능한 결과(D-43):** 후보가 없거나 부족할 때 적용 필터·부족 사유를 요약하고 **`전체 연도 보기` / `관련 장르 더 보기` / `영드·유럽 드라마 더 보기`**를 사용자 선택으로 제시한다. 검색 범위·장르·국가를 자동 완화하지 않는다.
41. **작품 식별 신뢰성(D-44):** 동명 작품·리메이크·시즌 혼동을 막기 위해 원제·최초 공개 연도·작품 고유 식별자로 동일성을 확인한다. 충분히 확인되지 않은 후보는 정규 순위에서 보류한다.
42. **시청 링크의 현재 유효성(D-45):** 국내 OTT·대여·구매·극장 링크가 오래되거나 작품별 연결이 불확실하면 검증된 링크만 표시하고 `확인 필요`로 안내한다. 유효한 국내 관람 경로가 하나도 확인되지 않으면 정규 TOP 10에서 제외한다.
43. **유튜브 검색 실패 분리(D-46):** 한국어 전체 줄거리 요약 영상을 찾지 못해도 추천 자체를 막지 않는다. `한국어 요약 영상 미확인` 표시 후 검증된 공식 예고편이 있으면 보조 제공하며, 임의 영상 링크를 만들지 않는다.
44. **순위의 불확실성 표시(D-47):** 비슷한 P-GSEI 점수 사이에 의미 없는 세밀한 우열을 강조하지 않는다. 점수와 함께 신뢰도·누락 지표·평가 시점을 제공하고 정밀도 및 동률 해소 기준은 `spec.md`에서 명시한다.
45. **사용자의 결과 통제(D-48):** 사용자는 검색 도중 **아직 완료되지 않은 분야의 검색을 취소**할 수 있고, 이미 완료·검증된 분야의 결과는 유지한다. 취소에 따른 API 요금 집계·차감 규칙은 실제 유료 호출 착수 여부를 기준으로 `spec.md`에서 확정한다.
46. **개인 데이터 통제(D-49):** 사용자 본인의 시청·찜·관심 없음·별점·취향 정보의 **내보내기와 삭제 요청 경로**를 제공한다. 즉시 삭제 대상·보존해야 하는 운영 기록·복구 불가 고지는 개인정보 보호 요구에 맞춰 `spec.md`에서 정의한다.
47. **공유 시 개인정보 제외(D-50):** 추천 목록 공유는 **개인 시청·찜·별점·취향·유료 사용량 없이 공개 작품 정보만** 포함하는 방식으로 추후 제공한다. 초기 버전에서는 개인정보가 들어간 사용자별 공유 링크를 생성하지 않는다.

## 3. 사용자와 가치

### 주요 사용자

- 처음에는 **본인과 승인된 Google 계정 사용자만** 이용한다(D-28 A안). **Google OAuth 로그인 + 승인 여부 확인**을 적용하고, 승인된 사용자들 사이에도 시청 기록·찜 목록을 분리한다. 향후 다중 사용자 공개 서비스로 확장할 수 있는 구조를 유지한다.

## 4. 대표 사용자 여정

### A. 새 영화·드라마 추천

**질문:** “26년 첩보 관련 미드나 영화 추천해줘.”

1. `26년`을 **2026년 공개**로 해석한다. 영화는 **세계 최초 공개 연도가 2026년인 작품**, 드라마는 **세계 최초 공개 연도가 2026년인 신규 시즌**을 대상으로 한다. 한국 개봉 연도가 2026년이어도 세계 최초 공개가 2025년인 영화는 기본 후보에서 제외한다.
2. `첩보`가 포괄적이므로 세부 장르를 **최대 4개**로 한 번만 제시한다. 선택 없이 전체로 진행할 수 있다.
3. 기본적으로 **미드 + 영화**를 검색하고, 국내 시청 가능 상태와 개인 시청 이력을 함께 확인한다.
4. 국내 시청·관람 경로(구독·무료·대여·구매 또는 영화의 현재 극장 상영)가 확인된 미시청 후보에 P-GSEI를 적용하고, **영화 TOP 10 / 드라마 TOP 10을 각각** 결제 유형과 무관한 점수순으로 출력한다. **일부 유효 지표로 점수 산정이 가능한 신작은 신뢰도·결측 정보와 함께 정규 순위에 포함**하되, **점수 산정이 불가능한 *기공개* 신작은 `평가 대기 신작`에 별도로 노출**한다. **아직 공개되지 않은 작품은 평점 수집 여부와 무관하게 `공개 예정작`에서 별도 표시**하며, 공식 글로벌 공개 계획이 있으면 한국 계획 미확정작도 `한국 공개 미확인` 상태로 포함한다. **이전 시즌을 아직 보지 않은 시리즈도 해당 연도 신규 시즌을 추천**하며, 입문자는 시즌 1부터의 권장 시청 순서를 확인할 수 있다. **이전 시즌의 국내 시청처가 없거나 확인되지 않아도 최신 시즌 추천은 유지**하고 선행 시즌 경고를 표시한다.
5. 기본 결과에서 포스터·**세계 최초 공개 연도와 한국 개봉 연도(확인 가능한 경우)**·평점 근거·한국 시청·관람처·이용 방식(구독/무료/대여/구매/극장 상영)·**한국어 자막/더빙 확인 상태(해당하는 경우)**·시청 상태·추천 이유를 한눈에 확인한다. 극장 상영 영화에는 검증된 예매 링크가 있는 경우 함께 제공한다.
6. 작품 상세를 열면 시즌 품질 추세·관련작 공개 연도·유튜브 요약 링크를 추가 표시한다.
7. **추천 결과 카드에서만** 시청 여부를 기록한다. 영화의 `봤음`은 해당 영화에, 드라마 카드의 `봤음`은 **현재 추천된 시즌에 즉시 적용**한다. 다른 시즌은 카드의 `시즌별 시청 관리`를 펼쳐 개별 수정한다. 저장 성공 시 **현재 추천 카드와 순위는 유지**하고 `시청 완료` 및 `되돌리기`를 표시한다. 이후 **새 추천 검색부터** 완료 항목을 제외한다. 초기 버전에서 별도 과거 시청작 검색·일괄 등록 화면은 제공하지 않는다. **`내 별점`은 완료 직후 같은 카드에 나타나지만, 별도 팝업 없이 원하는 때에만 1~5점을 입력·수정·해제할 수 있다(D-35).**
8. 추천 카드에서 **`찜`을 누르면 관심 목록에 저장**되고 카드에 찜 상태가 표시된다. 다시 누르면 찜을 해제할 수 있다. 관심 목록은 나중에 다시 열 수 있으며, 찜 여부로 추천 순위가 변하지 않는다. **찜한 작품에서 `봤음`을 저장하면 찜이 자동 해제**되므로 관심 목록에는 아직 보려는 작품만 남는다. 실수로 `봤음`을 누른 뒤 `되돌리기` 하면 그 체크로 자동 해제된 **기존 찜도 함께 복원**된다.
9. 유사 장르를 추가로 보고 싶을 때만 **`관련 장르 더 보기`**를 선택한다. 추가 검색은 원래 정규 영화·드라마 TOP 10을 변경하지 않고 **별도 섹션**으로 출력한다.
10. 영드·유럽 드라마를 더 보고 싶다면 **`영드·유럽 드라마 더 보기`**를 선택한다. 별도 **영드·유럽 드라마 TOP 10**을 표시하고 미국 드라마 TOP 10의 순위는 유지한다. 최초부터 영드·유럽을 명시했다면 해당 별도 순위를 직접 표시한다.
11. 서비스에 접속하면 **Google 로그인과 관리자가 수동 등록한 승인 계정 여부**를 확인한다. 승인된 계정만 추천 검색·시청 완료·찜 기능을 이용한다. 승인되지 않은 계정에는 접근 제한 안내를 표시하고 개인 추천 데이터나 다른 계정의 기록을 보여주지 않는다. 초기에는 사용자가 앱에서 가입 승인을 요청하는 기능이 없다.
12. 같은 조건으로 다시 검색할 때는 **최대 24시간 이내의 검증된 검색 캐시**를 우선 재사용하되 검색 결과의 **정보 확인 시점**을 표시한다. OTT·극장 관람 경로는 별도 최신성 기준으로 확인한다. 사용자별 최신 시청 상태와 찜은 다시 적용하며, 사용자가 `최신 정보로 다시 검색`을 누르면 외부 데이터에 대한 신규 조회·검증을 시도한다.

### B. 한국에서 시청·관람 가능한 작품만 탐색

**질문:** “올해 볼 만한 범죄 스릴러 중 한국에서 볼 수 있는 것만 10개 추천해줘.”

- **한국 내 구독·무료·대여·구매 또는 영화의 현재 극장 상영 중 실제 시청·관람 가능성이 검증된 작품**을 모두 기본 목록에 제시한다.
- 이용 유형은 `구독 포함` / `무료` / `대여(추가 결제)` / `구매(추가 결제)` / `극장 상영(영화)`으로 구분한다. 하나의 영화가 OTT와 극장에서 동시에 제공되면 확인된 두 경로를 함께 보여준다.
- P-GSEI 기본 순위는 결제·관람 방식이 아닌 작품 평가로 결정한다. 유료 제외·극장 제외 등은 사용자 필터로 추가할 수 있다.
- 국내 시청이 확인되면 **한국어 자막·더빙 지원 여부가 미확인/미지원이어도 제외하지 않는다.** 확인된 경우에만 지원 정보를 제공한다.
- **신규 시즌이 국내에서 제공되는 경우에는 선행 시즌의 국내 미제공/미확인을 이유로 정규 순위에서 제외하지 않는다.** 과거 시즌별 시청 경로와 경고를 함께 제공한다.
- 해외 전용 작품은 영화·드라마 어느 TOP 10의 빈자리도 채우기 위해 몰래 끼워 넣지 않는다. 영화가 이미 국내 개봉했어도 **현재 상영이 확인되지 않고 OTT/VOD도 없다면** 관람 가능 후보로 추정하지 않는다.
- 각 유형에서 조건에 맞는 작품이 6개라면 해당 유형은 **6개만 제공**하고 후보가 부족한 이유를 설명한다.
- 사용자 선택 시에만 국내 미제공 후보 또는 영드·유럽 작품까지 탐색 범위를 넓힌다. 단, **지역 확장과 국내 제공 필터는 독립적**이다. 영드를 찾아도 국내 제공이 확인되어야 기본 목록에 들어간다.

### C. 시즌 일부만 시청한 경우

**상황:** 시즌 1~2는 봤고 시즌 3은 보지 않았다.

- 시즌 3을 추천한 카드의 `봤음`을 누르면 **시즌 3만 바로 완료**된다. 해당 카드는 현재 추천 목록에 남고 `시청 완료`와 `되돌리기`를 표시한다. 시즌 1~2의 상태는 `시즌별 시청 관리`를 펼쳐 개별 기록·수정한다.
- `watched`인 시즌 1~2는 신규 추천 대상에서 제외한다.
- 시즌 3이 검색 연도·장르 조건을 만족하면 같은 시리즈를 **“새로 볼 시즌 있음”**으로 추천할 수 있다.
- **이전 시즌 시청 기록이 전혀 없거나 `unknown`이더라도** 시즌 3이 요청 연도에 새로 공개되고 한국 시청 가능성이 확인되면 추천한다. 이런 경우 시즌 1부터의 권장 시청 순서를 안내하되, 시즌 3 내용을 시청 전에 누설하지 않는다.
- 시즌별 공개 연월·평가와 함께 **한국 국내 시청 가능 여부를 시즌마다 구분**한다. 일부 선행 시즌이 국내 미제공 또는 미확인 상태라면 신규 시즌 추천을 유지하면서 **`선행 시즌 시청 경로 확인 필요`**를 표시한다. 아직 보지 않은 시즌의 주요 반전은 숨긴다.
- 해당 시즌에 대한 유튜브 **줄거리 요약 영상은 스포일러 경고 뒤에** 배치한다.

### D. 유튜브로 작품 파악

**상황:** 후보 작품에 관심이 있지만 내용을 더 알고 싶다.

- 작품 상세의 `관련 영상` 영역에서는 **한국어 전체 줄거리 요약을 우선 추천**하고, 공식 예고편·한국어 리뷰는 보조 영상으로 구분한다.
- 미시청 작품의 요약 영상은 **기본적으로 가린 상태**로 제공한다. 가림 화면에서는 `스포일러·결말 포함 가능` 안내만 우선 노출하며, 사용자가 펼치면 영상 제목·썸네일·채널명·게시일·재생시간(확인 가능 시)을 보여준다.
- **가림 해제**는 링크 열기가 아니라 메타데이터 노출만 수행한다. 이후 사용자가 링크를 클릭하면 YouTube의 **확인된 해당 영상 페이지**로 이동한다. 자동재생은 하지 않는다.
- 조건에 맞는 영상이 없으면 `검증된 요약 영상 없음`으로 표시하며 임의 링크를 만들지 않는다.
- 영상 제목이 다른 작품·다른 시즌을 가리키면 제외한다. 자동재생은 사용하지 않는다.

### E. 추천 카드에서 찜하고 나중에 다시 보기

**상황:** 추천된 작품을 지금 볼 수는 없지만 다음에 보고 싶다.

1. 영화 또는 드라마 추천 카드의 `찜`을 누른다. 저장이 확인되면 해당 카드에 찜 상태를 표시한다.
2. 사용자별 `관심 목록`에서 찜한 작품을 확인하고 원래 작품의 상세·한국 시청처로 이동할 수 있다.
3. 카드 또는 관심 목록에서 `찜 해제`를 할 수 있다. 저장 실패 시 성공 표시를 하지 않는다.
4. `찜`은 **시청 완료와 별도로 저장**되며 **P-GSEI 순위와 무관**하다. 다만 `봤음` 저장 성공 시에는 **D-10 A안에 따라 해당 작품의 찜을 자동 해제**한다.
5. 관심 목록은 별도 과거 시청작 등록 수단이 아니다. 찜은 **추천 결과 카드에서만 추가**한다. 이미 찜한 작품의 시청 완료 처리는 카드·관심 목록의 상태를 일치시킨다.
6. `봤음` 이후 `되돌리기` 시에는 **그 작업으로 제거되었던 원래 찜만 복원**한다. 원래 찜이 없었다면 찜 상태는 그대로 해제이며, 체크 이후 사용자가 찜을 직접 변경한 경우 최신 직접 변경을 우선한다.

## 6. 한국 시청 가능성 판단 원칙

### 국내 제공 여부는 작품 품질 점수와 분리

P-GSEI는 작품의 추천 적합도를 나타내고, **한국 시청 가능성은 필터·노출 조건**으로 처리한다. 시청할 수 있다는 이유만으로 IMDb 또는 P-GSEI 점수를 올리지 않는다.

| 이용 상태 | 기본 노출 의도 | 사용자가 알아야 할 정보 |
|---|---|---|
| 한국 구독형 OTT에 포함 | **기본 TOP N 포함** | 플랫폼명, 구독 필요, 확인 시각, 작품 바로가기 |
| 한국에서 무료 합법 시청 | **기본 TOP N 포함** | 서비스명, 광고 여부(확인 가능 시) |
| 한국에서 별도 대여·구매 가능 | **기본 TOP N 포함 + 추가 결제 배지** | 대여와 구매 각각 구분, 가격은 확인된 경우만 표시 |
| **한국 현재 극장 상영 확인(영화 한정)** | **영화 TOP 10 포함** | `극장 상영`, 상영 여부 확인 시각, 검증된 영화별 예매 링크(있는 경우), OTT 제공은 별도 구분 |
| 해외 플랫폼에서만 이용 가능 | 기본 TOP N 제외 | 사용자가 해외작 포함 선택 시 참고 영역 |
| 국내 정보 확인 불가 | `미확인`으로 명시 | 시청 가능하다고 추정하지 않음 |

**확정 D-01 (2026-10-14): B안.** 구독·합법 무료·별도 대여·구매 작품을 모두 기본 TOP N에 포함한다. **D-17 A안에 따라 국내 현재 극장 상영 중인 영화도 추가**한다. 추가 결제 및 극장 상영 여부는 배지·필터로 표시하되, 관람 방식 자체는 P-GSEI 점수를 바꾸지 않는다. 한국에서 어떠한 합법적 시청·관람 경로도 확인되지 않으면 기본 TOP N에 넣지 않는다. `구독만`, `무료만`, `극장 제외` 등은 선택 필터로 제공할 수 있다.

- OTT·극장 제공 지역은 `KR`을 기본으로 저장한다. 극장 상영 이력과 **현재 실제 상영**은 구분한다.
- 제작·최초 공개 플랫폼과 **현재 한국 시청 플랫폼**은 다른 필드다.
- 플랫폼별 권리 계약은 변동되므로 **확인 시점**을 함께 표시한다.
- 정상적인 한국 시청권을 확인할 수 없는 영상·지역 제한 서비스는 시청 가능으로 표시하지 않는다. 극장 예매 링크는 실제 영화와 상영 정보가 연결된 공식/검증된 페이지를 우선하며, 확인되지 않는 URL은 생성하지 않는다.
- **개인 OTT 구독 정보는 저장하거나 수집하지 않는다.** OTT 계정 비밀번호도 수집하지 않는다. 제공처 목록의 표시 순서는 구독 여부가 아니라 일관된 중립 규칙(예: 서비스명순/이용 방식 구분)에 따른다.

### D-04 확정: 한국어 자막·더빙은 정보로 표시하고 추천 진입 조건으로 사용하지 않음

**선택: A안(2026-10-14).** 한국 내 합법적 시청 경로가 확인된 작품은 한국어 자막·더빙이 없거나 확인되지 않아도 기본 추천에 포함한다.

- 표기: `한국어 자막 지원` / `한국어 자막 미지원` / `한국어 자막 미확인` 및 `한국어 더빙 지원` / `한국어 더빙 미지원` / `한국어 더빙 미확인`.
- **미확인과 미지원은 다른 상태**다. 언어 지원 정보가 없다는 이유로 미지원이라고 추정하지 않는다.
- 영상 플랫폼, 작품, 시즌마다 언어 지원이 다를 수 있으므로 **시청처별 확인 정보**를 우선 보여준다.
- 사용자 요청 시 `한국어 자막 확인된 작품만 보기`처럼 **일시적인 선택 필터**를 적용할 수 있다. 기본값은 필터 해제다.
- 언어 지원 정보에도 확인 출처와 시점을 기록하며, 확인되지 않은 경우 `미확인`으로 표시한다.

## 7. 유튜브 영상 링크 정책

### 목표

추천 결과에 추가적인 맥락을 주는 영상 경로를 제공한다. **유튜브는 영화 본편을 제공하는 OTT 시청처가 아니라, 예고편·리뷰·요약의 참고 정보 소스**로 취급한다.

### 영상 유형과 노출

1. **한국어 전체 줄거리 요약(우선):** 결말 포함 가능 여부와 무관하게 관련성이 높은 작품·시즌별 요약 영상을 우선 후보로 선정한다. 단, **사용자가 펼치기 전에는 영상 제목·썸네일·개별 링크를 모두 가린다.**
2. **한국어 리뷰·분석(보조):** 줄거리 요약과 구분하고, 스포일러 수준을 확인 가능할 때만 표시한다.
3. **공식 예고편(보조):** 한국에서 시청 전 분위기를 확인하기 위한 대안. 공식 채널 여부를 검증한다.

### 후보 선정 기준

- 영상 ID, 제목, 채널, 게시 상태 등 **실제 링크 존재 여부**를 확인한다.
- 영화/드라마의 **원제·한글명·개봉/공개연도·해당 시즌**을 사용해 동명이작을 구별한다.
- 한국어 콘텐츠 우선, 공식 채널·신뢰할 만한 리뷰 채널·정보 일치 여부를 종합한다.
- 조회수만으로 추천 영상을 결정하지 않는다. 줄거리 일치·영상 성격·스포일러 여부를 우선한다.
- 전체 줄거리 요약과 짧은 리뷰가 모두 있다면 **전체 요약을 먼저 배치**하고, 영상 유형·길이·결말 포함 가능성을 구분한다.
- 요약 영상이 저작권을 침해하는 본편 무단 업로드로 의심되거나 검증이 어려우면 채택하지 않는다.
- 가능하면 YouTube 공식 API 등 이용 조건에 맞는 검색 수단을 사용한다. 접근 제한·검색 결과 부족 시 `영상 없음/확인 불가`로 처리한다.
- YouTube 검색과 상세 검증은 **상세 펼침 시 수행**하거나 캐시에서 불러온다. 첫 추천 목록의 필수 대기 조건으로 삼지 않는다.

### 스포일러 보호

- 추천 카드 본문은 스포일러 최소화.
- 제목·썸네일 자체에 반전이 암시될 수 있으므로 **미시청 작품의 전체 요약 영상은 제목·썸네일·개별 URL까지 초기 응답에서 제외(서버단 마스킹 `spoiler_locked: true`)**.
- 사용자가 `스포일러 확인 후 보기`를 명시적으로 클릭하여 승인 API(`POST /api/v1/media/{media_id}/youtube/reveal`)를 호출한 시점에만 실제 제목, 썸네일, URL을 반환한다 (`spec.md SP-12.1`, `agents.md §3.4`).
- 가림 해제 버튼과 YouTube 열기 버튼을 분리한다. **가림 해제 전에는 스포일러 경고만 표시**, 열기 전에도 경고가 보이도록 하며 자동재생하지 않는다.
- 유튜브 링크 자체를 '무스포'라고 확언하지 않는다. 채널 설명·영상 메타데이터에서 확인될 때에만 `스포일러 없는 리뷰`로 표시한다.

### 카드 표시 예시 (실제 링크는 조회 후 제공)

```text
[미드] 슬로 호시스 | 신규 시즌: 공개 연월 | 한국 OTT: 확인된 서비스
[평점] P-GSEI, 관객·화제성·전문가·취향 점수
[상태] 시즌 1 ✓ 시청 | 시즌 2 □ 미시청
[상세] 시즌 평가 추세 / 스핀오프 관계 / 인기 원인
[관련 영상] 한국어 전체 줄거리 요약 우선 [스포일러·결말 가능 — 가림] | 공식 예고편(보조)
```

## 8. 기본 추천 결과와 상세 결과의 분리

### 첫 결과 화면 — 즉시 의사결정용

- **영화 TOP 10**과 **드라마 TOP 10**을 **별개 목록/섹션**으로 표시한다. 순위는 각 유형 내에서만 산출하며, 영화 1위와 드라마 1위의 점수를 상대적인 절대 우열로 해석하지 않는다.
- 순위, 포스터, 제목·원제, 영화/시리즈, **세계 최초 공개 연도(시리즈는 요청 연도 시즌 공개 연월)** 및 확인된 **한국 개봉 연도(영화)**. 한국 개봉 연도와 세계 최초 공개 연도는 서로 다른 필드다.
- P-GSEI(40/40/10/10), 근거 평점·평가 표본·데이터 신뢰도. **신작의 결측 평점은 `미확인`, 표본 부족은 `데이터 부족`으로 명시**하고, 산정할 수 없는 점수를 임의 생성하지 않는다.
- **정규 TOP 10과 별도 `평가 대기 신작` 영역 분리:** 실제 공개 연도·한국 시청·관람 경로가 검증된 **기공개 신작** 중 점수 산정에 필요한 유효 지표가 전혀 없는 작품을 별도로 보여준다. `P-GSEI 산정 불가`로 표기하고 TOP 10 순위 번호를 부여하지 않는다. 이 영역이 순위의 빈자리를 채우지 않으며, 작품 유형(영화/드라마)을 구별한다.
- **독립 `공개 예정작` 영역(D-19):** 검색 연도에 첫 공개 예정이지만 아직 개봉·시즌 공개되지 않은 작품은 TOP 10 및 `평가 대기 신작`에 포함하지 않는다. **공개 예정 연월(미확인 시 미확인), 확정·예정 구분, 한국 예정 관람 경로(확인된 경우), 출처·조회일**을 표시한다. 실제 공개 전 P-GSEI·순위 번호·실관람 가능 배지는 부여하지 않는다. D-20 A안에 따라 **글로벌 공개 예정이 공식 확인되었다면 한국 예정 경로가 없거나 미확인이어도 포함**한다. 국내 출시 계획은 `한국 공개 미확인`으로 표시하며 한국 시청 가능 상태로 오인시키지 않는다.
- **한국 시청·관람 경로**, 구독/무료/대여/구매/극장 상영 중 해당 유형과 추가 결제 표시, 확인 시각, 검증된 작품·예매 링크(있는 경우). 극장 상영은 영화에만 적용한다.
- **한국어 자막·더빙:** 지원/미지원/미확인 상태. 플랫폼별 차이가 있을 경우 각각 구분.
- 한 줄 배경·인기 이유·추천 근거.
- **추천 카드에서만** 시청 상태 변경. 영화는 해당 영화, 드라마는 **현재 추천된 시즌을 `봤음`으로 즉시 저장**하고 `시즌별 시청 관리` 펼침에서 다른 시즌을 개별 변경. 저장 완료 카드에는 **`시청 완료` + `되돌리기`**를 노출하고 해당 검색 결과/순위는 유지한다. 처음부터 모든 시즌 선택 팝업을 표시하지 않음.
- **`찜/나중에 보기` 토글:** 추천 카드에서 관심 목록에 추가하거나 해제하고, 사용자별 관심 목록에서 다시 볼 수 있다. `찜`은 추천 순위에 반영하지 않으며 **`봤음` 저장 성공 시 자동 해제**된다.
- **`관심 없음`/`추천 제외` 토글(D-31~D-33):** 추천 카드에서 원치 않는 작품을 제외 상태로 저장·해제한다. 체크 직후 현재 카드와 순위는 유지하되 제외 표시를 제공하며, **다음 신규 검색부터** 해당 작품을 제외한다. 추천 점수 자체를 바꾸지 않고 사용자별 필터로 적용한다. 드라마는 동일 시리즈 전체 시즌에 적용하고 스핀오프는 별도 관리한다(D-32 A안). 기존 찜은 관심 없음 저장 성공 시 자동 해제하고, 제외를 되돌리면 이전 찜을 조건부 복원한다(D-33 A안).
- **`내 별점`(D-34·D-35 A안):** `봤음` 저장 성공 후 현재 추천 카드에 1~5점 평가 UI를 노출한다. **별점 입력 팝업·입력 유도는 제공하지 않고**, 원하는 때에 카드 내에서 등록·수정·해제한다. 미입력도 정상 처리되며 별점 저장 실패는 성공으로 표시하지 않는다. 등록된 점수는 **다음 신규 추천의 개인 취향 10%**에서만 반영하고 현재 순위는 유지한다.
- **관련 유튜브 영상 있음/조회 가능** 표시(영상 검색은 상세에서 수행 가능).
- **`관련 장르 더 보기`** 버튼을 제공하되, 기본 검색 단계에서는 인접 장르 작품을 별도 탐색하지 않는다. 클릭한 경우에만 기존 요청의 연도·국내 가용성·시청 완료 제외를 유지하며 관련 작품을 별도 섹션에 보여준다.

### 작품 상세 — 선택할 때 조회

- 시즌별 최초 공개 연월, 핵심 갈등·배경·평가, **시즌 품질 상승/하락/유지**.
- 시청 진도를 넘는 결말·반전·사망/배신 정보는 기본 숨김.
- 스핀오프·프리퀄·시퀄·관련 영화의 **최초 공개 연도**, 공식 관계 및 권장 시청 순서.
- **개별 유튜브 영상 링크**: 한국어 전체 줄거리 요약 우선, 리뷰·공식 예고편 보조. 미시청 작품은 제목·썸네일·링크 기본 가림, 해제 후 유형·채널·재생시간·스포일러 경고 표시.
- 평점/국내 제공처/영상의 정보 출처와 조회 시점.

### 프랜차이즈 관계 예시

```text
브레이킹 배드 (2008) — 원작
├─ 베터 콜 사울 (2015) — 프리퀄·스핀오프
└─ 엘 카미노 (2019) — 후속 영화
```

## 9. 간결한 사용자 응답 흐름 — 4단계

```text
1. 입력 해석 (모호할 때만 장르 최대 4개 제안)
      ↓
2. 작품 후보·평점·한국 OTT/극장 상영·시청 이력 병렬 조회
      ↓
3. 필수 근거 검증 + 국내 가용성 필터 + 시청 제외 + P-GSEI 계산/산정 가능성 분류
      ↓
4. 분야별 검증·정렬 완료 시 영화 TOP 10 또는 드라마 TOP 10부터 즉시 출력
      ├─ 나머지 분야는 검색 중 표시 (양쪽을 기다리지 않음)
      ├─ 검증된 기공개 평가 대기 신작은 분야별 별도 영역에 표시
      ├─ 미공개 예정작은 점수·순위 없는 별도 영역에 표시
      └─ 선택 작품 상세: 시즌 평가 / 관계작 / 유튜브 영상 지연 조회
```

- **LLM 호출 최소화:** 규칙으로 판별 가능한 연도·필터는 코드 처리; 예외적인 의도 분석과 설명 생성만 Google Gemini API 활용.
- **비용 상한 보호(D-37·D-38 A안):** 신규 Google Gemini API 호출 전 서비스 월간 예산과 사용자별 **일일** 유료 검색·호출 한도를 확인한다. 두 한도 중 하나라도 초과하면 유료 호출만 차단하며 검증된 캐시 결과와 사용자 기록 접근은 허용한다. 동시 실행·청구 지연, 일일 리셋 정책은 `spec.md`에 정의한다.
- **검증된 캐시 우선(D-30 A안):** 동일 조건의 확정 추천 결과는 최대 24시간 재사용하고 정보 확인 시점을 표시한다. 사용자는 `최신 정보로 다시 검색`으로 강제 재조회할 수 있다. 국내 OTT·대여·구매·극장 상영은 결과 캐시와 별도의 최신성 검증을 적용하며, 시청 완료·찜·관심 없음·계정 승인 상태는 현재 사용자 데이터로 반영한다.
- **공통 공개 데이터 캐시(D-41 A안):** 승인된 사용자 간에는 평점·시즌·OTT·관계작 등 검증된 **비개인화 공개 데이터**와 개인정보 없는 일반 AI 분석 결과만 공유한다. 개인 시청 상태·취향·별점·찜·제외 목록과 사용자별 최종 추천 순위는 별도 격리한다. 공통 데이터 캐시가 있어도 개인정보 필터·P-GSEI는 현재 사용자 기준으로 적용한다.
- **독립적인 섹션 출력:** 영화/드라마의 조사·검증·순위 계산은 서로를 기다리지 않는다. 먼저 검증 완료된 섹션은 즉시 확정 표시하고, 다른 섹션은 `검색 중`으로 둔다. 지연·실패 시 완료된 섹션을 유지한다.
- **동시 조회:** 연결 가능한 공급자에 병렬 조회. 느린 공급자는 타임아웃·부분 수집을 적용하되, **분야별 검증 완료 전 미확정 TOP 10을 먼저 보여주지 않는다.**
- **품질 보장:** 최신성/출처 없는 OTT·영화 예매 링크를 즉석에서 생성하지 않는다. 확실하지 않으면 `미확인`이라고 표기. 평가 데이터가 적은 신작을 일률 제외하지 않고 결측 및 점수 신뢰도를 함께 전달한다.
- **측정할 목표(가설):** 캐시 적중 초기 결과 ≤5초 / 신규 조회 초기 결과 ≤15초. 공급자 의존성을 포함한 목표이며 보장은 아니다.
- **점진적 상세:** 요약 영상 링크·프랜차이즈 맥락은 작품을 펼칠 때 가져와 체감 시간을 단축한다.

## 11. 검증 가능한 수용 시나리오

**AC-01 — 연도 해석:** `26년 첩보` 입력 시 **세계 최초 공개 연도가 2026년인 영화** 또는 **세계 최초 공개 연도가 2026년인 신규 시즌**이 후보가 된다. 2026년에 한국에서 처음 개봉했더라도 전 세계 최초 공개가 2025년인 영화와 단순히 2026년에 유행한 구작은 기본 후보가 아니다.

**AC-02 — 장르 질문 최소화:** 넓은 장르에는 세부 선택지 최대 4개, 구체적 `CIA 잠입 액션`에는 불필요한 추가 질문 없음.

**AC-03 — 국내 가용성:** OTT/VOD와 현재 국내 극장 상영(영화만)이 모두 확인되지 않은 작품을 한국에서 볼 수 있다고 표시하지 않으며, TOP N 부족을 정직하게 설명한다.

**AC-04 — 이용 유형 분리:** 동일 작품이라도 `구독 포함`, `무료`, `대여`, `구매`, `극장 상영(영화)`, `미확인`을 혼동하지 않는다. 국내 제공이 확인된 대여·구매·현재 극장 상영 영화도 TOP N 후보에 포함하고, 동일 P-GSEI일 때 이용 방식만을 이유로 순위를 변경하지 않는다.

**AC-05 — 점수 재현:** 동일 평가 데이터와 가중치라면 40/40/10/10 개인화 점수가 동일하게 계산된다. 데이터 신뢰도는 별도 표시한다.

**AC-06 — 시청 제외:** 시청 완료 영화는 다음 검색에서 제외. 기존 시즌만 본 시리즈는 검색 조건에 맞는 새로운 미시청 시즌이 있으면 추천 가능.

**AC-07 — 유튜브 영상:** 영화/시즌과 정확히 일치하는 **한국어 전체 줄거리 요약**을 1순위로 선정한다. 실제 영상 검증에 성공했을 때만 개별 링크를 제공하며, 없으면 링크를 추측하지 않는다.

**AC-08 — 스포일러:** 추천 본문은 미시청 시즌의 반전·결말을 노출하지 않는다. 유튜브 전체 줄거리 요약의 **제목·썸네일·링크**는 사전 경고와 가림 해제 액션 전까지 표시하지 않으며 자동재생하지 않는다.

**AC-09 — 시즌·관계작:** 시즌 공개 연월, 평점 추세, 스핀오프 관계·최초 공개 연도를 확인 가능한 범위에서 제공한다.

**AC-10 — 성능:** 유튜브 영상 조회 실패·지연 때문에 작품 추천 목록 전체가 실패하거나 무기한 멈추지 않는다.

**AC-11 — 상태 영속성:** 사용자 시청 체크를 저장한 뒤 새 세션에서 불러오면 동일 상태가 유지된다.

**AC-12 — 출처:** 한국 OTT 경로·평점·영상 링크·한국어 지원 상태의 확인 시각과 정보 소스를 추적할 수 있다.

**AC-13 — 한국어 지원:** 국내 제공이 확인된 작품은 한국어 자막·더빙이 `미확인` 또는 `미지원`이어도 기본 추천에 포함한다. `미확인`을 `미지원`으로 오표기하거나 다른 플랫폼의 지원 상태를 동일하게 적용하지 않는다.

**AC-14 — 유형별 순위 분리:** 동일한 검색 조건에서 영화 최대 10편과 드라마 최대 10시리즈(연도 조건이 있으면 해당 연도 신규 시즌 기준)를 **독립 순위**로 반환한다. 예를 들어 영화 6편, 드라마 8편만 검증되면 6편/8편만 노출한다. 국내 미제공·기시청 후보로 빈자리를 채우지 않는다. **D-16 A안에 따라 각 분야의 검증·점수 산정 완료 시 독립 확정 표시한다.**

**AC-15 — 추천 결과에서만 시청 상태 등록:** 최초 이용 시 별도 과거 시청작 검색·일괄 등록 화면을 요청하지 않는다. 추천 카드에서 영화 또는 시즌을 개별 `봤음` 처리하면 저장되고, 같은 사용자 계정의 후속 추천에서는 완료 항목이 제외된다. 미체크(`unknown`)는 미시청 확정으로 오인하지 않는다.

**AC-16 — 드라마 시즌 체크 최소 클릭:** 드라마 카드의 `봤음`을 누르면 선택 팝업 없이 **현재 추천된 시즌만** 시청 완료로 저장한다. 예컨대 시즌 3 카드라면 시즌 1·2·4의 기록은 바뀌지 않는다. `시즌별 시청 관리`를 펼치면 시즌별 현재 상태를 확인하고 각각 수정·체크 해제할 수 있다. 저장 실패 시 완료로 확정 표시하지 않는다.

**AC-17 — 현재 추천 유지 및 다음 검색 제외:** 현재 TOP 10의 `봤음`을 저장해도 해당 카드의 순위·자리·표시는 유지하고, `시청 완료` 및 작동하는 `되돌리기`를 노출한다. 동일 `recommendation_run_id`의 결과를 다시 조회해도 해당 추천 스냅샷은 유지하되 최신 시청 상태를 반영한다. **새로운 추천 실행**에서는 완료한 영화·시즌을 제외한다. `되돌리기` 저장 성공 후에는 후속 검색의 제외 조건을 해제한다. 저장 실패 시 UI를 완료로 확정하지 않고 오류를 표시한다.

**AC-18 — 찜 저장·해제 및 순위 불변:** 추천 카드에서 `찜`을 누르면 사용자별 관심 목록에 등록되고 재접속 후에도 유지된다. 카드 또는 관심 목록에서 찜을 해제할 수 있다. 찜 토글 전후 동일 `recommendation_run_id`의 목록·순위·P-GSEI는 변하지 않는다. `봤음` 상태와는 별도로 저장하되 D-10 정책에 따라 시청 완료 시 자동 해제하며, 저장 실패를 성공으로 표시하지 않는다.

**AC-19 — D-10 시청 완료 시 찜 자동 해제:** 찜한 영화를 `봤음`으로 저장하면 해당 영화는 관심 목록에서 제거되고 시청 이력은 남는다. 찜한 드라마의 **추천 시즌**을 `봤음`으로 저장해도 해당 작품의 찜이 해제된다(작품 단위 찜). 동시 변경은 중간 상태 없이 성공하거나 실패해야 하며, 현재 `recommendation_run_id`의 카드·순위는 유지한다. `되돌리기` 시에는 **D-11 A안에 따라 해당 작업으로 해제된 기존 찜을 함께 복원**한다.

**AC-20 — D-11 되돌리기 시 기존 찜 복원:** 원래 찜한 영화/드라마의 `봤음` 처리로 찜이 자동 해제되었다면, 같은 체크를 `되돌리기` 했을 때 이전 시청 상태와 기존 찜이 함께 복구된다. 원래 찜하지 않은 작품의 `되돌리기`에서는 새 찜이 생성되지 않는다. `봤음` 이후 사용자가 찜을 다시 수동으로 조작했다면 되돌리기로 그 최신 상태를 덮어쓰지 않는다. 시청·찜 복구는 원자적으로 처리하고 저장 실패를 성공으로 표시하지 않으며, 같은 추천 실행의 기존 순위는 유지한다.

**AC-21 — D-12 신작의 평가 부족 허용:** 공개 연도와 한국 시청 경로가 확인된 영화/신규 시즌은 IMDb·Rotten Tomatoes 등 일부 평가가 없거나 표본이 적어도 추천 후보에서 자동 배제하지 않는다. 존재하지 않는 평점은 `미확인`, 제한된 평가 근거는 `데이터 부족/신뢰도 낮음`으로 표시한다. 확보된 지표만을 활용해 계산하고, 계산에 충분한 근거가 아예 없으면 P-GSEI를 `산정 불가`로 표시한다. 결과에 넣기 위해 평점을 만들어내거나 결측을 0점으로 대체하지 않는다. 결측치에 따른 점수 계산·정렬 상세 정책은 `spec.md`에서 정의한다.

**AC-22 — D-13 신규 시즌과 미시청 선행 시즌:** 요청 연도에 시즌 3이 공개되고 한국에서 해당 시리즈를 시청할 수 있는 경우, 시즌 1·2의 시청 이력이 없거나 `unknown`이어도 시즌 3을 포함한 해당 작품을 드라마 추천 후보에서 제외하지 않는다. 카드에 `처음 보는 시리즈라면 시즌 1부터`라는 권장 시청 순서와 기존 시즌들의 공개 연월·확인된 한국 시청 가능성을 표시한다. 시즌 1·2 시청 완료가 없다는 사실만으로 감점하거나 신규 시즌 공개 연도를 과거 시즌 공개 연도로 바꾸지 않는다. 스포일러 방침 D-02에 따라 미시청 시즌의 주요 반전은 노출하지 않는다.

**AC-23 — D-14 점수 산정 불가 신작의 별도 배치:** 같은 조건으로 검색했을 때 일부 평가 지표가 확보되어 P-GSEI 계산이 가능한 신작은 결측·신뢰도와 함께 정규 영화/드라마 TOP 10 후보에 들어간다. 반면 평점·화제성 등 유효 평가 지표가 전혀 없어 P-GSEI를 계산할 수 없는 신작은 **정규 TOP 10의 순위 번호 없이 `평가 대기 신작` 영역**에만 표시한다. 이 작품은 TOP 10의 빈자리를 채우지 않으며, 평가 대기 영역에서도 공개연도와 한국 합법 시청 경로는 검증되어야 한다. 지표가 새로 확인되어 점수 산정이 가능해지면 **다음 추천 실행부터** 정규 순위 후보로 이동할 수 있다.

**AC-24 — D-15 선행 시즌 제공이 불확실한 신규 시즌:** 2026년 공개된 시즌 3의 국내 합법적 시청처가 검증되고 시즌 1이 국내 미제공, 시즌 2가 국내 제공 미확인 상태라도, 시즌 3을 추천 대상으로 유지한다. 카드에는 **`선행 시즌 시청 경로 확인 필요`**를 표시하고 시즌 1은 `국내 미제공 확인`, 시즌 2는 `국내 제공 미확인`, 시즌 3은 `국내 제공 확인`으로 구분한다. 이전 시즌의 국내 제공이 확인되지 않았다는 사실을 국내 미제공 확정으로 과장하지 않으며, 확인되지 않은 링크를 만들지 않는다. 시즌 1부터의 권장 시청 순서와 미시청 시즌 스포일러 보호를 유지한다.

**AC-25 — D-16 분야별 점진적 출력:** 동일 검색에서 영화 분야가 먼저 데이터 수집·한국 제공처 검증·시청 제외·P-GSEI 계산·정렬을 완료하면, **영화의 최종 TOP 10을 즉시 확정 표시**하고 드라마는 `검색 중`으로 표시한다(반대도 동일). 드라마가 이후 검증을 마치면 독립적으로 최종 TOP 10을 추가한다. 드라마 공급자 타임아웃·실패 시에도 영화의 완료 결과·순위·`recommendation_run_id`의 스냅샷을 유지하고 드라마에는 `실패/재시도` 상태를 보여준다. 어느 분야도 검증 전 임시 순위를 TOP 10으로 표시하지 않는다. 작품 상세·유튜브 조회는 두 분야의 초기 확정 출력을 지연시키지 않는다.

**AC-26 — D-17 국내 극장 상영작 포함:** 동일한 연도·장르 조건을 만족하는 영화가 OTT/VOD에는 없더라도 **현재 한국 극장 상영 중이라는 근거**가 확인되면 영화 TOP 10 후보에 포함한다. 카드에는 `극장 상영`을 명확히 표시하고, 영화별 예매 링크가 실제로 검증된 경우에만 노출한다. 국내 상영이 종료되었거나 개봉 이력만 확인되는 영화는 극장 경로만으로 포함하지 않으며, 해외 극장 상영만 확인된 영화도 포함하지 않는다. 같은 영화가 OTT/VOD와 극장에서 동시에 제공되어도 **한 작품으로 중복 없이 순위화**한다. 드라마의 TOP 10은 극장 상영 여부로 변경되지 않는다.

**AC-27 — D-18 세계 최초 공개 연도 필터:** 영화 A가 전 세계에서 2025년 처음 공개되고 한국에서는 2026년 개봉한 경우, 현재 국내 상영 중이더라도 `2026년 영화` 기본 후보에 포함하지 않는다. `2025년 영화` 검색에서는 다른 필수 조건을 만족하면 후보가 될 수 있다. 영화 카드에는 `세계 최초 공개: 2025`와 `한국 개봉: 2026`을 별개로 표시한다. 드라마는 시리즈 원작 공개 연도가 아니라 **검색 연도에 공개된 시즌의 세계 최초 공개 연도**로 판단한다. 세계 최초 공개일의 경계(영화제 첫 상영·일반 공개 등), 공개일 출처 우선순위, 연도 미확인 처리는 `spec.md`에서 정의한다.

**AC-28 — D-19 공개 예정작의 별도 영역 및 무점수 처리:** 조회일이 2026-10-14인 상태에서 2026년 12월 세계 최초 공개 예정인 영화 A는 해당 연도 영화 TOP 10에 들어가지 않고 **`공개 예정작`** 영역에만 표시한다. 발표된 공개 예정 월·예정 관람 플랫폼/국내 극장 공개 계획·출처를 확인된 범위에서 표시하지만, **P-GSEI 점수·인기 순위·실제 관람 가능 여부를 추정하지 않는다**. 이미 2026년에 공개됐지만 평가 데이터가 전무한 영화 B는 `공개 예정작`이 아니라 **`평가 대기 신작`**으로 분류한다. 첫 공개가 확인되고 평가가 축적되면 이후 신규 검색에서 적절한 영역으로 재분류하며 과거 검색 결과 스냅샷은 보존한다.

**AC-29 — D-20 글로벌 예정작의 한국 공개 미확인 허용:** 2026년 12월 전 세계 첫 공개가 공식 발표된 영화 C에 대해 한국 극장·OTT 예정 정보가 발견되지 않았어도, 해당 작품은 `공개 예정작`에 표시된다. 카드에는 `글로벌 공개 예정: 2026.12`와 `한국 공개 미확인`을 구분하고 확인된 공식 발표 출처·조회일을 기록한다. 국내 상영·시청 가능 배지, 임의의 국내 링크, P-GSEI 점수 및 정규 TOP 10 순위는 부여하지 않는다. 발표가 아닌 루머만 있는 작품은 공식 확인 글로벌 예정작으로 취급하지 않는다.

**AC-30 — D-21 연도 미입력의 기본 검색 범위:** 조회일이 2026-10-14일 때 `재미있는 첩보 영화와 미드 추천`처럼 연도가 빠진 요청은 **2024·2025·2026년**에 세계 최초 공개된 영화 또는 해당 연도에 세계 최초 공개된 시즌을 대상으로 한다. UI에 `기본: 2024~2026`을 표시하며, 사용자가 `전체 연도 보기`를 선택하면 연도 조건 없이 검색한다. `2026년 첩보`처럼 연도를 직접 지정한 요청은 최근 3개 연도로 확장하지 않고 **지정된 2026년만** 검색한다. 추천 순위·국내 시청처·공개 예정작 분리 정책은 기존 확정안대로 유지한다.

**AC-31 — D-22 추천 후보 부족 시 수동 연도 확장:** 연도 미입력 검색의 기본 범위(2026년 기준 2024~2026년)에서 검증된 미시청 영화가 7개, 드라마가 4개라면 영화 TOP 7·드라마 TOP 4를 그대로 확정 출력한다. 부족한 3개·6개를 임의 작품이나 과거 연도로 채우지 않으며, `평가 대기 신작`과 `공개 예정작`도 충원에 사용하지 않는다. `전체 연도 보기`를 사용자가 선택하면 그때 연도 제한을 해제하고 **새 추천 실행**을 시작하며, 해당 실행에서도 국내 시청·관람 가능 여부·시청 이력·P-GSEI·영화/드라마 분리·검증 원칙은 유지한다. 명시적 연도 검색 또한 사용자 지시 없이 범위를 변경하지 않는다.

**AC-32 — D-23 직접 장르만 정규 TOP 10 포함:** 사용자가 `2026년 첩보 미드와 영화`를 검색했을 때, 정보기관 활동·첩보 임무·스파이 침투·정보전이 작품의 핵심인 후보 A는 국내 시청 가능성 등 다른 필수 조건을 통과하면 정규 추천 대상으로 평가한다. 반면 첩보가 부수적 설정일 뿐 주요 내용은 일반 정치 갈등·국제 범죄 수사인 후보 B는 **정규 TOP 10에 포함하지 않고** `관련 장르 추천`으로 분리한다. 직접 관련 후보가 6편뿐이어도 다른 분야 작품으로 10편을 채우지 않으며, `관련 장르 추천`의 존재는 정규 P-GSEI 순위·사용자 시청 완료 제외·공개 연도 필터를 변경하지 않는다. 애매한 장르 관련성은 출처 없는 추측으로 확정하지 않는다.

**AC-33 — D-24 관련 장르 수동 확장:** `2026년 첩보 미드와 영화` 검색 시 인접 장르 추가 검색을 자동 수행하지 않고 영화·드라마 정규 결과 및 `관련 장르 더 보기` 버튼을 제공한다. 사용자가 이 버튼을 누를 때만 정치 스릴러·국제 범죄 액션 등 검증된 인접 장르 후보를 추가 검색한다. 추가 결과는 별도 `관련 장르 추천`으로 표시하며, 기존 영화/드라마 TOP 10의 순위·개수·상태는 변경하지 않는다. 버튼을 누르지 않은 사용자는 인접 장르 검색으로 인한 추가 대기·호출 비용을 부담하지 않는다. 확장 결과에도 검색 연도·한국 관람 가능·시청 기록 필터를 동일하게 적용한다.

**AC-34 — D-25 영드·유럽 드라마 수동 확장:** `2026년 첩보 미드와 영화`를 검색하면 기본 영화 TOP 10 및 미국 드라마 TOP 10을 먼저 검증·출력한다. 미국 드라마가 6개만 확인되더라도 영국·유럽 드라마를 자동 조회해 정규 드라마 순위를 채우지 않는다. `영드·유럽 드라마 더 보기`를 사용자가 선택하면 그때 추가 후보를 검색한다. 확장 결과도 세계 최초 공개 연도·직접 관련 장르·한국 시청 가능 여부·시청 완료 제외·P-GSEI 및 출처 검증 조건을 지킨다. `2026년 영드 추천`처럼 사용자 최초 요청에 영드가 명시된 경우에는 추가 버튼 선택 없이 영드를 직접 검색한다. D-26 A안에 따라 영드·유럽 드라마는 별도 TOP 10으로 표시하고 기존 미국 드라마 순위를 바꾸지 않는다.

**AC-35 — D-26 영드·유럽 드라마 독립 TOP 10:** 기본 `2026년 첩보 미드와 영화` 검색에서 미국 드라마 TOP 10이 확정된 후 사용자가 `영드·유럽 드라마 더 보기`를 선택하면, **기존 미국 드라마 TOP 10의 작품 구성·순위·시청/찜 카드 상태를 그대로 유지**하고 `영드·유럽 드라마 TOP 10` 섹션을 신규 생성한다. 이 섹션에는 원 요청의 공개 연도·핵심 장르·한국 관람 가능성·시청 제외 필터를 만족하고 평가된 **영국·유럽 드라마만 최대 10개**를 독립 P-GSEI 점수순으로 보여준다. 적합한 작품이 4개면 4개만 표시하며 미국 작품으로 빈자리를 채우지 않는다. 사용자가 처음부터 `2026년 영드 추천`이라고 요청한 경우 확장 클릭을 기다리지 않고 영드·유럽 드라마의 해당 섹션을 직접 조회·출력한다.

**AC-36 — D-27 Google OAuth 인증 및 계정별 동기화:** 승인된 사용자가 Google 계정 A로 PC에 로그인해 영화 `봤음`과 시리즈 `찜`을 저장한 뒤 같은 계정 A로 모바일에 로그인하면 해당 상태를 그대로 조회하고 변경할 수 있다. 별도로 승인된 Google 계정 B로 로그인하면 계정 A의 시청/찜 데이터를 조회·수정할 수 없다. 로그아웃했거나 인증 세션이 만료된 상태에서는 보호된 사용자 데이터를 읽거나 변경할 수 없으며, 서비스는 Google 비밀번호를 직접 수집·저장하지 않는다. 승인되지 않은 계정은 D-28에 따라 이용을 제한한다.

**AC-37 — D-28 승인 계정 전용 서비스:** 관리자가 승인한 Google 계정 A는 OAuth 로그인 후 추천 검색·시청 체크·찜 목록을 사용할 수 있다. 승인 목록에 없는 계정 C는 Google 인증이 성공해도 서비스를 이용할 수 없으며 추천 실행·시청/찜 API·사용자 데이터 접근은 거부되고 접근 제한 안내가 표시된다. 로그인·권한 거부된 요청 때문에 Google Gemini API 검색 비용이 발생하지 않는다. 승인된 계정 A와 B의 시청/찜 기록은 서로 격리된다. 승인 상태가 철회된 계정은 재요청 때 권한이 거부된다.

**AC-38 — D-29 관리자 수동 등록·철회:** 관리자만 사용할 수 있는 서비스 외부의 운영 절차를 통해 Google 계정 A를 승인하면, 해당 계정은 OAuth 인증과 서버 측 승인 확인 후 서비스를 이용할 수 있다. 관리자가 A의 승인을 철회하면 **이후 보호된 API 요청은 거부**되고 시청·찜 데이터에도 접근할 수 없다. 비승인 사용자는 앱 안에서 가입 요청이나 셀프 승인 절차를 실행할 수 없다. 승인 계정 추가·철회에 웹 관리자 화면은 필요하지 않다. 단, 수동 관리 과정에서도 다른 사용자 기록은 조회·수정되지 않아야 한다.

**AC-39 — D-30 검증 결과 캐시 및 수동 갱신:** 승인된 사용자가 동일한 연도·장르·매체·검색 범위로 검색한 뒤 24시간 이내에 다시 요청하면, 검증된 추천 결과 캐시가 유효할 때 이를 재사용하며 **정보 확인 시점**을 명확히 표시한다. 이후 영화의 시청 완료를 체크하거나 찜을 변경하면, 캐시로 재검색하더라도 **현재 사용자 상태**가 적용되고 시청 완료 영화는 새로운 결과에서 제외된다. 캐시가 있는 상태에서 `최신 정보로 다시 검색`을 누르면 원천 검색·평점 조사 및 검증을 새로 시도한다. 캐시가 24시간을 초과했으면 그대로 최신 결과로 간주하지 않는다. 국내 OTT/VOD 및 극장 상영 정보는 결과 캐시와 독립적으로 유효 기간을 확인해 갱신 또는 `미확인` 처리하고, 종료된 극장 상영이나 사라진 OTT 경로를 검증 없이 현재 관람 가능으로 표시하지 않는다. 영화와 드라마 섹션의 선완료 출력(D-16)은 유지한다.

**AC-40 — D-31 관심 없음 기능:** 승인 사용자 A가 추천된 영화 X에서 `관심 없음`을 체크하면 서버 저장 성공 후 현재 추천 카드와 기존 순위는 유지되고 해당 카드에 제외 상태와 `해제`를 표시한다. A가 새 추천 검색을 실행하면(같은 검색 조건의 24시간 캐시를 이용하는 경우 포함) X는 추천에서 제외된다. 사용자가 제외를 해제하면 이후 신규 검색에서 X가 다시 후보가 될 수 있다. `관심 없음`은 시청 완료로 간주되지 않고, P-GSEI 원 점수를 수정하지 않는다. 승인 사용자 B의 추천에는 A의 제외 기록이 적용되지 않는다. 드라마는 D-32 A안에 따라 동일 시리즈의 모든 기존·향후 시즌에 적용하되 별도 작품인 스핀오프는 자동 제외하지 않는다. 저장 실패 상태를 성공으로 표시하지 않는다.

**AC-41 — D-32 드라마 관심 없음의 전체 시리즈 적용:** 승인 사용자 A가 드라마 X의 시즌 3 추천 카드에서 `관심 없음`을 저장하면, **현재 추천 카드·순위는 유지**되고 다음 신규 검색에서는 X의 **시즌 1·2·3·4 및 이후 출시된 시즌 5** 모두 추천 후보에서 제외된다. 24시간 추천 캐시를 재사용하더라도 동일하게 제외한다. 단, 공식 스핀오프 Y는 **별도 작품 ID**이므로 별도로 제외 표시하지 않았다면 장르·연도·국내 시청 가능 등 다른 조건이 충족될 때 추천할 수 있다. X의 `관심 없음`을 해제하면 다음 검색부터 X의 미시청 시즌이 다시 추천 후보가 된다. 제외·해제는 사용자별로 분리되며 평가 점수는 변경하지 않는다.

**AC-42 — D-33 관심 없음과 찜 동시 처리:** 승인 사용자 A가 기존에 `찜=true`인 영화 X를 `관심 없음`으로 저장하면, 저장 성공 후 X는 관심 목록에서 제거되고 `관심 없음=true`, `찜=false`가 일관되게 반영된다. 이후 `관심 없음`을 해제하면 **해당 제외 작업으로 자동 해제됐던** `찜=true`가 복원된다. 원래 `찜=false`였다면 해제 시 찜을 새로 생성하지 않는다. 제외한 뒤 사용자가 `찜`을 직접 변경했으면 제외 해제 시 그 최신 수동 선택을 덮어쓰지 않는다. 저장 중 실패하거나 충돌이 발생하면 일부 변경만 성공한 것처럼 표시하지 않는다. 같은 추천 실행의 카드와 순위는 유지하고 다음 새 검색부터 관심 없음 필터를 적용한다. 계정 B의 찜·관심 없음 상태는 영향받지 않는다.

**AC-43 — D-34 선택형 개인 별점 및 개인화:** 승인 사용자 A가 영화 X에서 `봤음`을 저장하면 **별점을 입력하지 않아도** 시청 완료가 성공한다. 이후 1~5점 중 하나를 저장·수정·해제할 수 있으며, 드라마는 추천된 **시즌 단위**로 독립 기록한다. 개인 별점은 A의 다음 신규 추천에서 **P-GSEI 개인 취향 10% 내부** 근거로만 반영되고 재미·관객 만족도 40%, 화제성 40%, 전문가 평가 10%의 가중치나 출처 평점 자체를 바꾸지 않는다. 별점이 없는 사용자도 사전 설정된 취향 프로필로 추천받으며, 계정 B의 데이터에는 영향을 주지 않는다. 시청 완료가 해제된 경우 개인 별점은 **D-36 A안에 따라 보존·비활성화**하며, 재완료 시 자동 복원한다. 저장 상태·복원 원자성의 상세 구현은 `spec.md`에서 정의한다. 별점 저장 실패를 성공으로 표시하지 않으며, 현재 추천 실행의 순위는 유지한다.

**AC-44 — D-35 카드 내 별점 입력·팝업 없음:** 승인 사용자 A가 미시청 영화 X에서 `봤음`을 누르면 먼저 시청 완료가 저장되고, **별점 입력창이나 별점 제출 요구 없이** 같은 추천 카드에 `내 별점`(1~5점)이 표시된다. 별점을 누르지 않아도 완료 상태가 유지되며, 이후 별점을 4점으로 저장했다가 5점으로 수정하거나 해제할 수 있다. 드라마 시즌 2를 `봤음` 처리한 경우에도 해당 시즌 카드에서만 별점을 입력·수정한다. 점수 저장이 실패하면 이전에 확정된 별점 상태를 유지하고 성공 알림을 띄우지 않는다. 별점 입력 전후 현재 추천 스냅샷과 순위는 변하지 않으며, 저장된 점수는 **다음 신규 검색의 개인 취향 10%**에만 반영된다.

**AC-45 — D-36 시청 취소 시 별점 보존·비활성화:** 승인 사용자 A가 영화 X에 `봤음=true, 내 별점=4점`을 저장한 뒤 `되돌리기`를 누르면 **시청 상태만 미완료로 변경되고 4점 기록 자체는 보존**된다. 이때 별점 UI는 활성 평가로 보이지 않으며, 이후 새 추천의 **개인 취향 10% 계산에서 해당 4점은 제외**된다. 다시 같은 영화 X에 `봤음`을 저장하면 별도 입력 없이 4점이 복원된다. 드라마는 선택한 **시즌 단위**로 동일하게 동작하며 다른 시즌 평가를 변경하지 않는다. 별점을 원래 입력하지 않은 경우에는 복원할 점수를 생성하지 않는다. 시청 상태·별점 활성화 변경 저장이 실패하면 부분 성공으로 표시하지 않으며 다른 계정 기록에도 영향이 없다.

**AC-46 — D-37 월 예산 및 사용자별 검색 제한:** 관리자가 월별 Google Gemini API 예산과 사용자별 유료 검색·호출 한도를 설정한다. 승인 사용자 A가 한도 내에서 새로운 검색을 실행하면 서버가 사용량·추정 비용을 확인한 뒤 실행하고, 실제 응답의 사용량과 비용을 사용자별/월별로 기록한다. 월 예산 소진 또는 사용자 한도 초과가 예상되면 **신규 유료 검색 및 추가 Gemini API 호출을 차단**하고 `검색 한도 도달`과 적용 사유를 표시한다. 사용자는 이때도 **기존 검증된 캐시 추천, 자신의 시청·찜·관심 없음·별점 기록**을 열람하고, Gemini API 호출 없이 가능한 상태 변경을 실행할 수 있다. 캐시를 표시하면서 실제로 Google Gemini API를 추가 호출한다면 이를 무료 조회로 취급하지 않는다. 사용량 동시성·확정 비용 지연에 대비해 보수적 추정/여유분을 적용한다. 정확한 한도 숫자, 청구량 반영 지연, 월초 리셋, 예외 및 장애 복구 방식은 `spec.md`에서 정의한다.

**AC-47 — D-38 일일 사용자 한도 및 전체 월 예산:** 서로 다른 두 승인 사용자가 각각 자신의 일일 유료 검색 횟수로 집계되며 한 사람의 검색이 다른 사람의 일일 할당량을 차감하지 않는다. 사용자 A가 일일 한도를 소진한 상태에서는 같은 날 신규 유료 검색을 실행할 수 없고, 다음 날 일일 카운터가 초기화되어도 **서비스 전체 월 예산이 소진된 상태라면 신규 유료 호출이 여전히 거부**된다. 검증 캐시 열람과 Gemini 호출 없는 시청·찜·별점 변경은 양쪽 한도에 영향을 받지 않는다. 하루의 경계 시간대, 실제 한도값, 집계 기준과 동시 요청 처리 방식은 `spec.md`에서 정한다.

**AC-48 — D-39 요청 단위 유료 검색 차감:** 승인 사용자 A가 `2026년 첩보 영화와 미드 추천`을 새로 검색하여 영화·드라마 두 분야의 순위를 병렬로 얻더라도 **일일 유료 검색은 1회**만 차감된다. 이후 `전체 연도 보기`로 별도 유료 확장 검색을 실행하면 **1회 추가** 차감되고, `최신 정보로 다시 검색`도 실제 새 Gemini API 호출이 필요한 독립 요청이라면 1회 차감된다. 동일 조건의 **검증 캐시를 추가 Gemini API 호출 없이** 열람하면 횟수는 차감되지 않는다. 내부에서 Google Gemini API를 여러 차례 사용했더라도 검색 횟수를 그 수만큼 늘리지 않고 **실제 사용 토큰·비용은 모두 월 예산 관리에 기록**한다. 한도 내 유료 호출이 시작되지 않은 실패·취소, 부분 실패와 동시 중복 요청에 대한 차감/환불은 `spec.md`에서 일관되게 검증한다.

**AC-49 — D-40 작품 상세 무료 조회·선택형 AI 분석:** 승인 사용자 A가 작품 상세를 열어 저장된 시즌 평점 추세·관련 작품 공개연도·검증된 유튜브 링크를 확인해도 신규 Gemini API 호출이 없으므로 **유료 검색 횟수 0회**다. 상세 열람만으로 `AI 상세 분석`이 자동 시작되지 않는다. A가 `AI 상세 분석`을 명시 선택하여 신규 Gemini 분석이 실행되면 실행 전 1회 차감 대상임을 표시하고, 사용자 일일 한도 **1회**와 서비스 월 예산을 확인한 뒤 실행한다. 추가 분석이 필요 없는 기존 검증 결과 재열람은 **0회**다. 한도 초과면 신규 분석만 차단하고 기존 상세 조회는 유지한다. 신규 유료 호출 착수 전의 취소·실패와 실행 후의 실패·부분 완료에 대한 차감·환급 규칙은 `spec.md`에서 정의한다.

**AC-50 — D-41 공개 데이터 공통 캐시·개인화 결과 격리:** 승인 사용자 A가 작품 X의 평점·시즌 공개일·한국 OTT·공식 스핀오프와 비개인화 작품 분석을 검증해 공통 캐시에 저장한 뒤, 다른 승인 사용자 B가 동일 자료를 조회한다. 캐시가 유효하고 **추가 Google Gemini API 호출 없이** 자료를 제공할 수 있다면 B의 일일 유료 검색 횟수는 **0회**이며 공통 데이터의 확인 시점이 표시된다. 다만 B의 영화·드라마 추천 목록은 **B 자신의 시청 완료·찜·관심 없음·별점·취향**으로 필터·점수 재계산한 결과여야 하며 A의 개인 상태·개인화 프롬프트·P-GSEI 순위 및 추천 결과 스냅샷은 B에게 노출되지 않는다. 미승인 사용자는 공통 캐시에도 접근하지 못한다. OTT·극장 가용성 검증 기한이 지났다면 최신성 확인 또는 `미확인`으로 처리하고 낡은 국내 가용성을 확정 정보로 보이지 않는다. 개인 정보가 포함된 분석은 공통 캐시에 기록되지 않는다.

**AC-51 — D-42 부분 제공자 장애:** IMDb 점수 조회가 실패했지만 다른 허가된 평가 데이터와 공개 연도·핵심 첩보 소재·현재 국내 관람 경로가 확인된 작품 X는 이용 가능한 점수로 P-GSEI 평가 가능 여부를 판단하고, 부족 지표를 `미확인` 표시한다. 국내 관람 경로가 검증되지 않은 작품 Y는 정규 TOP 10에 넣지 않는다. 검증된 영화 섹션이 먼저 완료되면 드라마 공급자 장애와 무관하게 표시한다. 실패 공급자에 대한 무한 재시도는 수행하지 않는다.

**AC-52 — D-43 결과 부족 시 사용자 선택만 확장:** `2026년 첩보 미드`에서 검증 결과 3개만 나오면 미드 TOP 3과 적용 조건·부족 이유를 보여준다. `전체 연도 보기`, `관련 장르 더 보기`, `영드·유럽 드라마 더 보기`는 표시하지만 클릭 전에는 해당 확장 검색·비용 발생이 없다.

**AC-53 — D-44 식별 혼동 방지:** 같은 번역 제목의 영화 X(2022)와 영화 Y(2026)가 있을 때 원제·최초 개봉 연도·공인 작품 식별자가 다른 사실이 확인되면 서로의 평점·OTT·예고편을 합치지 않는다. 시즌 번호가 다른 드라마 평가도 교차 적용하지 않는다. 식별이 모호한 후보는 확인 전 정규 순위에서 보류한다.

**AC-54 — D-45 시청처 링크 검증:** 작품 X의 국내 구독 링크는 유효하지만 대여 링크가 만료됐다면 구독 경로만 제공하고 만료 대여 링크는 `확인 필요`로 구분한다. 검증된 국내 OTT/VOD/극장 경로가 전혀 없는 작품 Y에는 `한국에서 시청 가능` 배지를 표시하지 않고 정규 TOP 10에서 제외한다.

**AC-55 — D-46 요약 영상 미확인:** 작품 X의 한국어 줄거리 요약 YouTube 영상이 검색·검증되지 않아도 X의 정규 추천·점수에는 영향을 주지 않는다. 상세 카드에 `한국어 요약 영상 미확인`을 표시하고 공식 예고편의 실제 영상 URL만 확인된 경우 보조 노출한다. 영상 제목·썸네일의 스포일러 가림 정책은 유지한다.

**AC-56 — D-47 점수 신뢰도 표기:** 영화 A의 P-GSEI가 88.1점, B가 88.0점으로 산정되었더라도 UI는 출처·결측·평가 표본·조회일·신뢰도를 함께 제공한다. 점수의 사소한 차이를 통계적으로 확정적인 작품성 차이로 설명하지 않고, 반올림·동률 순서가 재실행 때 일치하도록 `spec.md`에서 고정한다.

**AC-57 — D-48 미완료 분야 취소:** 영화 섹션이 완료된 뒤 드라마 섹션이 검색 중인 상황에서 사용자가 드라마만 취소하면 영화 섹션의 작품·순위·시청 상태는 변경되지 않는다. 이미 개시된 Google Gemini API 비용이나 검색 횟수가 자동으로 무료로 되돌아간다고 보장하지 않고, 명확한 정산 규칙을 적용한다.

**AC-58 — D-49 개인 데이터 통제:** 승인 사용자 A가 자신의 시청·찜·관심 없음·별점·취향 내보내기 또는 삭제를 요청하면 본인 권한을 검증하고 A의 데이터만 처리한다. 승인 사용자 B의 기록은 전혀 변하지 않는다. 삭제 범위와 필요한 보존 예외·복구 가능성을 사전 안내하며 구체적 절차는 `spec.md`에서 정의한다.

**AC-59 — D-50 공유 시 정보 분리:** P0에서는 다른 사용자에게 노출되는 개인화 공유 링크를 생성하지 않는다. 후속 공개 작품 공유 기능이 출시되어도 사용자 A의 시청 진도·개인 별점·취향·찜·사용량이 URL 또는 비인가 응답에 포함되지 않아야 한다.

## 12. 비목표와 경계

- 유튜브 영상을 재업로드하거나 영상 저작물을 내려받아 재배포하지 않는다.
- 지역 제한을 우회해 해외 OTT를 한국에서 볼 수 있는 것처럼 표시하지 않는다.
- 출처가 불명확한 점수·영상 URL·스트리밍 경로를 생성하지 않는다.
- OTT 개인 계정에 로그인해 시청 이력을 임의 수집하지 않는다. 초기 시청 체크는 **추천 결과에서만 수동 입력**한다.
- **Google OAuth 로그인은 서비스 사용자 인증에만 사용**한다. Google 메일·Drive 등 계정 콘텐츠 접근 권한은 기본적으로 요청하지 않으며, 비밀번호를 직접 수집하지 않는다. **인증과 이용 승인(인가)은 분리**하고, 승인되지 않은 계정은 추천 API를 포함해 보호된 서비스에 접근할 수 없다.
- **초기 버전에는 과거 시청작 검색·일괄 등록·CSV 가져오기·외부 시청 이력 동기화 기능을 만들지 않는다.**
- **초기 버전에는 앱 내 가입 요청·승인 대기열·관리자 승인 UI를 구현하지 않는다.** 승인·철회는 별도의 관리자 수동 운영 절차로 처리한다.
- 실시간 글로벌 OTT 편성·평가 사이트의 완전한 커버리지를 보장하지 않는다. 제공처 장애 시 일부 필수 검증을 통과한 후보만 출력하고 미확인 값을 만들어 넣지 않는다(D-42).
- 사용자 요청 없이 장르·연도·국가 범위를 자동 확장하지 않는다(D-43).
- 초기에는 사용자 개인화 추천의 공개 공유 링크를 만들지 않는다(D-50).
- 사용자가 요구하지 않으면 미시청 시즌의 결말·반전 정보를 노출하지 않는다.
- 추천 정확도를 높인다는 이유로 초기 목록 반환 전에 모든 시즌/영상의 심층 분석을 수행하지 않는다.

**D-41 공통 공개 캐시 공유와 개인 정보 분리:** 공개 작품·시즌·평점·한국 시청/상영 경로·관계작 및 비개인화 AI 분석만 승인 사용자 간 공통 캐시로 재사용한다. 사용자 식별자·시청·찜·관심 없음·개인 별점·취향 프로필·개인화 검색/추천 결과는 공통 캐시 키와 페이로드에서 배제하고 사용자별 보호 영역에 저장한다. 공통 캐시 조회 전 계정 승인 검증, 응답 전 사용자별 필터 및 P-GSEI 적용을 보장한다. 캐시 키의 공개/개인 데이터 경계, 추론 입력에 포함된 개인 정보 감지, 결과의 혼합 위험 차단, 작품·지역·언어·출처·데이터 버전별 캐시 키, 만료·동시성·무효화 정책, 취향/시청/관심 기록 변경 후 재평가, 데이터 공급자 재배포 및 캐시 이용 권한은 `spec.md`에서 명세한다. **D-30의 최대 24시간과 OTT/극장 별도 최신성 기준을 그대로 적용한다.**

**D-42~D-50의 구현 이관:** 외부 제공처 장애·부분 성공의 최소 검증 기준과 타임아웃, 무결성 있는 작품/시즌 식별, 시청 URL 최신성 판단, 유튜브 검색 실패 시 대체 UI, 점수 정밀도·동률 처리, 진행 중 섹션 취소와 비용 정산, 개인정보 내보내기·삭제 절차, 공유 정보의 공개/개인 경계를 `spec.md`에서 정의한다. **연도·장르·국가 자동 확대는 하지 않으며**, 사용자가 요청할 때만 새 검색을 실행한다.

## 14. 의사결정 로그 — D-01~D-50 확정

### D-01 (확정): 한국에서 '볼 수 있다'의 범위

**선택: B안(2026-10-14).** 한국에서 구독·무료·대여·구매 가능한 작품을 **모두 기본 추천 TOP N에 포함**한다. 각 작품의 실제 이용 방식, 추가 비용 유무, 확인된 링크를 표시한다. 대여·구매 전용 작품을 별도 후보로 밀어내지 않는다.

### D-02 (확정): 유튜브 요약 영상 기본 노출·스포일러 수준

**선택: B안(2026-10-14).** 관련 영상에서는 **한국어 전체 줄거리 요약**을 우선 추천한다. 영상에 반전·결말이 포함될 수 있으므로 **사전 경고 및 클릭 전 가림 처리**를 적용한다. 사용자가 가림을 해제할 때에만 영상 제목·썸네일·개별 링크를 표시하며, 자동재생은 하지 않는다. 공식 예고편과 일반 리뷰는 보조 선택지다. 최초 추천 목록의 응답 시간에 영향을 주지 않도록 영상 탐색은 상세 화면에서 지연 조회한다.

### D-03 (확정): 내 구독 OTT 등록과 표시 우선순위

**선택: B안(2026-10-14).** **개인 구독 OTT 정보를 저장하지 않는다.** 구독·무료·대여·구매를 포함한 국내 제공 플랫폼을 모두 동등하게 표시하며, 이미 구독 중이라는 이유로 특정 서비스를 상단에 배치하거나 P-GSEI 순위에 가산하지 않는다. **특정 플랫폼 또는 이용 방식만 보기**는 저장 없는 일시적인 화면 필터로 제공할 수 있다.

### D-04 (확정): 한국어 자막·더빙 정보가 없는 작품의 추천 처리

**선택: A안(2026-10-14).** 국내에서 시청 가능한 작품은 모두 기본 추천에 포함한다. 한국어 자막·더빙은 확인 가능한 범위에서 별도 표시하고, `미확인`이더라도 제외하지 않는다. `미지원`도 기본 제외 조건이 아니다. 세부 검증·표시 규칙은 `spec.md`에서 명세한다.

### D-05 (확정): 영화·드라마 순위 구분

**선택: B안(2026-10-14).** **영화 TOP 10과 드라마 TOP 10을 각각 독립적으로 추천**한다. 각 순위에는 동일한 P-GSEI의 40/40/10/10 구성 원칙을 적용하되, 영화와 시리즈의 서로 다른 평점·화제성 자료는 유형 특성에 맞춰 정규화한다. 한 유형에서 검증된 후보가 10개 미만이면 확인된 수만 표시한다. 시리즈는 신규 시즌을 해당 연도 후보로 보되, 카드가 동일 작품의 중복으로 채워지지 않게 한다. 화면은 두 섹션을 구분하여 첫 응답 속도를 유지하고, 시즌 상세·영상은 지연 조회한다.

### D-06 (확정): 과거 시청 이력을 처음에 어떻게 등록할 것인가?

**선택: B안(2026-10-14).** **추천 결과 카드에서만 작품·시즌별로 개별 시청 체크**한다. 초기 버전에는 과거 시청 작품을 제목으로 검색해서 일괄 등록하는 별도 화면을 만들지 않는다. 체크 전에는 `unknown` 상태이므로 과거에 본 작품이 최초 추천에 나올 수 있지만, 체크·저장 이후 후속 추천에서는 자동 제외된다. 추천 결과가 아닌 독립 등록 경로는 초기 구현 범위에서 제외한다.

### D-07 (확정): 추천 카드에서 드라마 시청 완료를 어떻게 체크할 것인가?

**선택: A안(2026-10-14).** 추천 카드의 `봤음` 버튼은 **현재 추천된 시즌만 즉시 시청 완료로 저장**한다. 다른 시즌은 같은 추천 카드의 `시즌별 시청 관리`를 펼쳐 개별 체크·해제한다. 시즌 선택 팝업을 기본으로 띄우지 않는다. 저장 실패 시 시청 완료가 확정된 것처럼 보여주지 않는다.

### D-08 (확정): `봤음` 체크 직후 현재 추천 카드의 처리

**선택: B안(2026-10-14).** `봤음` 저장 성공 즉시 카드에 **`시청 완료` + `되돌리기`**를 표시하되, **현재 영화 TOP 10 / 드라마 TOP 10의 구성과 순위는 변경하지 않는다.** 사용자가 지금 보던 추천 목록을 계속 확인할 수 있어야 한다.

- **현재 추천 실행의 결과 스냅샷은 보존:** 같은 `recommendation_run_id`를 다시 열어도 작품과 순위는 유지한다. 단, 상태 배지는 최신 DB 시청 기록으로 표시한다.
- **다음 추천 검색부터 제외:** 새 검색을 시작할 때 최신 시청 기록을 필터로 적용한다. 시청 완료 영화와 추천 시즌은 새 TOP 10 후보에서 제외한다.
- **실수 복구:** `되돌리기`는 동일 작품/시즌의 시청 완료 기록을 해제한다. 저장 성공 이후 신규 검색에서 다시 추천될 수 있다.
- **저장 실패:** `시청 완료`로 확정 표시하지 않으며 오류 안내 및 재시도 기회를 제공한다.
- **정렬 안정성:** 체크로 빈자리를 즉시 채우거나 현재 순위를 재산정하지 않는다. 목록 업데이트는 새 검색 실행 시에만 한다.

### D-09 (확정): 관심 작품 `찜/나중에 보기`의 초기 버전 포함 여부

**선택: A안(2026-10-14).** 초기 버전(P0)에 추천 카드 `찜` 토글과 사용자별 `관심 목록`을 포함한다.

- 추천 카드에서 **찜 추가/해제**하고, 저장 성공 시 찜 상태를 표시한다.
- 별도의 **관심 목록 화면**에서 저장한 작품을 조회하고 찜을 해제할 수 있다.
- `찜`은 `봤음`과 독립된 상태이며 **P-GSEI 점수·추천 순위를 바꾸지 않는다**.
- 추천 화면에서 이미 본 작품이라도 현재 검색 스냅샷은 유지하는 D-08 원칙을 그대로 따른다.
- 찜 상태는 사용자별로 영속 저장되며 PC·모바일에서 동일하게 조회할 수 있다.
- **D-10 A안 확정:** 해당 작품 또는 추천 시즌 `봤음` 저장 성공 시 작품 단위 찜을 자동 해제하고 시청 기록은 유지한다.

### D-10 (확정): 찜한 작품을 `봤음`으로 체크하면 어떻게 처리할까?

**선택: A안(2026-10-14).** `봤음` 저장이 성공하면 **해당 작품의 찜을 자동 해제**하여 관심 목록에서 제거한다. 시청 완료 기록은 유지한다.

- **영화:** 시청 완료 → 작품 찜 자동 해제.
- **드라마:** 추천 카드의 현재 시즌을 `봤음` 완료 → 해당 시리즈에 연결된 **작품 단위 찜 자동 해제**. 다른 시즌의 시청 상태는 변경하지 않는다.
- **화면:** 현재 추천 카드와 순위는 D-08대로 유지하며, 카드의 `찜` 상태만 해제하고 `시청 완료`를 표시한다. 관심 목록에는 즉시 반영한다.
- **저장 일관성:** 시청 상태 저장과 자동 찜 해제는 함께 성공해야 하며 일부만 성공한 것처럼 표시하지 않는다. 실수로 `봤음`을 취소하면 **D-11 A안에 따라 자동 해제된 기존 찜도 함께 복원**한다.
- **점수:** 자동 해제는 P-GSEI 또는 추천 순위에 영향을 주지 않는다.

### D-11 (확정): `봤음`을 되돌릴 때 자동 해제된 찜도 복원할까?

**선택: A안(2026-10-14).** `봤음`을 잘못 체크한 뒤 `되돌리기`를 누르면 **해당 체크 직전의 시청 상태와 자동 해제된 기존 찜을 함께 복원**한다.

- 원래 찜 상태가 `true`였다면 해당 `봤음`으로 자동 해제된 찜을 복원하고 관심 목록에도 다시 보이게 한다.
- 원래 찜 상태가 `false`였다면 `되돌리기`로 새로운 찜이 생기지 않는다.
- 추천 카드와 순위는 유지하며, 되돌리기가 저장되면 **이후 새 검색**에서 미시청 후보로 다시 포함될 수 있다.
- 단, 체크 이후 사용자가 찜을 직접 다시 변경한 경우에는 최신 수동 변경을 우선해 덮어쓰지 않는다. 이를 위해 **체크 이전 상태·자동 해제 여부·변경 버전**을 `spec.md`에서 기록하도록 명세한다.
- 저장 실패 또는 동시 업데이트 충돌 시에는 복원 성공을 표시하지 않고 재조회·오류 처리를 수행한다.

### D-12 (확정): 평점이 충분하지 않은 신작도 추천할까?

**선택: A안(2026-10-14).** 2026년 신작처럼 IMDb·Rotten Tomatoes·Metacritic의 점수 또는 평가 표본이 적더라도, **요청한 공개 연도와 한국 내 합법적 시청처가 검증되면** 기본 영화/드라마 TOP 10의 **후보에 포함**한다.

- 평점과 표본 수는 검증된 값만 사용하고, 누락 지표는 `미확인`, 표본 부족은 `평가 데이터 부족`으로 명시한다.
- 계산 가능한 지표만으로 P-GSEI를 평가하되, **비교 가능한 신뢰도를 별도로 표시**한다. 부족한 지표를 0점이나 추정치로 채우지 않는다.
- 점수를 산정할 근거 자체가 없다면 P-GSEI는 `산정 불가`로 표시하며 **확인되지 않은 가상 점수로 TOP 순위를 만들지 않는다**.
- 평가 데이터가 충분한 후보와 신작의 순위 편향을 줄이는 정규화·결측 보정·순위 정책 및 낮은 신뢰도 배치 규칙은 `spec.md`에서 정한다.
- 이미 확정된 국내 시청 가능 여부, 시청 완료 제외, 영화/드라마 별도 TOP 10 등 나머지 조건은 그대로 유지한다.

### D-13 (확정): 신규 시즌만 공개된 시리즈의 이전 시즌을 아직 보지 않았다면?

**선택: A안(2026-10-14).** 요청한 연도에 신규 시즌이 공개되고 국내 시청 가능성이 검증되면, 선행 시즌 시청 기록이 없거나 `unknown`이어도 드라마 추천 후보에 포함한다.

- **추천 진입:** 예컨대 시즌 3이 2026년에 공개되었다면 시즌 1·2 미시청/미확인도 추천 배제 조건이 아니다. 2026년 공개 시즌을 추천 기준으로 삼는다.
- **정주행 안내:** 입문자에게 시즌 1부터 차례대로 보도록 권장하고, 과거 시즌 공개 연월과 국내 시청처를 확인 가능한 범위에서 표시한다. 과거 시즌 중 한국 제공 정보가 불확실한 경우 `미확인`으로 표기한다.
- **스포일러:** 신규 시즌 핵심 반전이나 선행 시즌의 결말을 기본 카드에 노출하지 않는다. 전체 줄거리 YouTube 영상은 D-02에 따라 별도 가림 처리한다.
- **기존 원칙 유지:** 같은 시리즈를 시즌별로 중복 TOP 10에 올리지 않고 하나의 작품 카드 안에서 신규 시즌과 이전 시즌을 함께 표시한다. 사용자가 `봤음`을 누를 때는 D-07대로 추천된 시즌에만 적용한다.

### D-14 (확정): P-GSEI를 산정할 수 없는 신작의 추천 결과 배치

**선택: A안(2026-10-14).** 영화·드라마 정규 TOP 10은 P-GSEI를 산정할 수 있는 작품으로만 구성한다. 요청 연도에 공개되었고 한국 내 합법 시청 경로가 확인되었지만 **평점·화제성 등 유효 평가 데이터가 전혀 없어 P-GSEI 산정이 불가능한 신작**은 `평가 대기 신작` 영역으로 분리한다.

- **부분 데이터 확보:** 일부 유효 지표가 있어 P-GSEI를 계산할 수 있으면 결측 데이터와 신뢰도 표시를 포함하여 정규 TOP 10 후보로 유지한다. 실제 점수 정규화 및 최소 산정 조건은 `spec.md`에서 정의한다.
- **산정 불가:** `P-GSEI 산정 불가`와 평가 부족 사유를 명시한다. 정규 TOP 10의 순위 번호를 주거나 무리하게 점수·화제성을 추정하지 않는다.
- **추천 수:** 점수 산정 가능 후보가 10개 미만이면 그 수만큼 노출한다. `평가 대기 신작`으로 빈자리를 채우지 않는다.
- **변경 시점:** 이후 유효 평가 데이터가 확인되면 **다음 신규 검색**에서 정규 순위 후보로 다시 평가한다. 과거 `recommendation_run_id`의 결과 스냅샷은 유지한다.
- **일관성:** D-12의 ‘평가 부족 신작도 발견 가능하도록 한다’는 원칙을 유지하면서 인기순 TOP 10의 정량 비교를 보호한다.

### D-15 (확정): 선행 시즌의 국내 시청처가 없거나 확인되지 않는 경우

**선택: A안(2026-10-14).** 요청 연도에 새 시즌이 공개되고 **해당 신규 시즌 자체의 한국 합법 시청처가 확인되었다면**, 과거 시즌의 국내 제공이 없거나 미확인이어도 정규 드라마 TOP 10 추천 후보에서 제외하지 않는다.

- **정규 추천 유지:** 요청 연도의 시즌을 실제로 국내에서 볼 수 있는 한, 선행 시즌 제공 정보가 부족하다는 이유로 해당 작품의 점수를 깎거나 순위를 제거하지 않는다.
- **시즌별 상태 구분:** `국내 제공 확인` / `국내 미제공 확인` / `국내 제공 미확인`을 엄격히 구별한다. `미확인`은 미제공 확정이 아니다.
- **안내 문구:** 선행 시즌 중 `국내 미제공 확인` 또는 `국내 제공 미확인`이 하나라도 있으면 **`선행 시즌 시청 경로 확인 필요`** 경고를 표시한다.
- **정주행 안내:** 시즌 1부터의 공개 연월·권장 시청 순서와 확인된 국내 제공처만 보여준다. 링크가 확인되지 않으면 만들어내지 않는다.
- **스포일러·속도:** 이전 시즌의 결말을 가리지 않고 요약하지 않으며, 선행 시즌의 상세 제공처 확인은 필요 시 지연 조회해 첫 결과를 늦추지 않는다.
- **D-01/D-13과의 일관성:** 신규 시즌의 국내 제공 사실은 필수, 선행 시즌의 한국 제공 사실은 필수 아님. 국내 미제공 작품을 볼 수 있다고 오인시키지 않는다.

### D-16 (확정): 영화·드라마 TOP 10을 표시하는 시점

**선택: A안(2026-10-14).** 영화와 드라마를 독립적인 실행 단위로 조사·검증·P-GSEI 계산·정렬하고, **각 분야의 최종 순위가 확정되는 즉시 먼저 화면에 표시**한다. 완료되지 않은 분야는 `검색 중`으로 안내한다.

- **분야별 확정 결과:** 영화가 먼저 완료되면 영화 TOP 10을 즉시 제공하고 드라마는 `검색 중`으로 둔다. 드라마가 먼저 끝나면 반대로 처리한다.
- **미검증 순위 노출 금지:** 작품·국내 가용성·평점 및 시청 이력 필터 검증이 끝난 분야만 순위가 확정된다. 임시 순위와 추정 순위를 TOP 10으로 표시하지 않는다.
- **분야 간 실패 격리:** 한쪽 공급자가 지연·실패해도 다른 분야의 완료 결과는 유지한다. 실패한 분야에는 상태 및 재시도 동작을 제공한다.
- **세부 조회 지연:** 시즌별 상세, 스핀오프, 유튜브 요약 검색은 작품 상세를 열 때 수행한다.
- **구현 세부 위임:** 섹션별 상태 전환, 스트리밍/SSE 또는 폴링 선택, 재시도·타임아웃·재접속 및 스냅샷 안정성은 `spec.md`에서 정의한다.

### D-17 (확정): 극장 상영 중인 영화의 추천 포함 범위

**선택: A안(2026-10-14).** **국내 극장에서 현재 상영 중인 영화도 OTT/VOD 제공 여부와 무관하게 정규 영화 TOP 10 후보에 포함**한다.

- 영화 카드에 `극장 상영`을 표시하며, 국내 상영 여부·확인 시각을 검증한다.
- 검증된 **해당 영화의 극장 예매 링크**가 있으면 제공한다. 확인하지 못한 예매 URL은 만들지 않는다.
- 극장에서만 볼 수 있는 영화와 OTT/VOD로도 볼 수 있는 영화는 **같은 영화 TOP 10 순위**에서 P-GSEI로 평가한다. 관람 방식에 따른 점수 가감은 하지 않는다.
- 같은 영화가 여러 경로로 제공되면 카드 하나에 이용 경로를 모두 표시한다.
- 국내 극장 상영이 현재 확인되지 않고 OTT/VOD도 확인되지 않으면 국내 관람 가능 후보로 추정하지 않는다.
- 드라마 순위, 스포일러 방침, 시청·찜 정책은 기존 확정안을 그대로 유지한다.

### D-18 (확정): 연도 검색의 국내 개봉일과 세계 최초 개봉일 기준

**선택: A안(2026-10-14).** 연도를 지정한 검색에서 영화는 **세계 최초 공개 연도만** 기본 연도 필터로 사용한다. 한국 개봉 연도는 별도로 표시하고, 국내 개봉 연도를 세계 최초 공개 연도의 대용으로 사용하지 않는다.

- 예: 영화가 세계 최초로 2025년에 공개되고 한국에는 2026년에 개봉했다면, `2026년 영화` 검색에서는 제외한다. `2025년 영화`에서는 한국 관람 가능성 등 다른 조건을 만족하면 추천 후보가 될 수 있다.
- 영화 카드에 **`세계 최초 공개 연도` / `한국 개봉 연도`**를 구분해 표시한다. 한국 개봉 연도를 확인할 수 없으면 추측하지 않고 `미확인`으로 표시한다.
- **D-17과의 관계:** 현재 국내 극장 상영 중이라는 사실은 한국 관람 가능성 필터를 충족시키지만, **세계 최초 공개 연도 조건을 면제하지 않는다.**
- 드라마는 기존 원칙대로 **해당 신규 시즌의 세계 최초 공개 연도**를 사용하며, 시리즈 전체의 최초 공개 연도와 혼동하지 않는다.
- 영화제 첫 공개·일반 극장 개봉·OTT 공개 등 최초 공개 사건의 우선순위는 `spec.md`에서 명확히 정의하고 검증 가능한 출처를 요구한다.

### D-19 (확정): 아직 공개되지 않은 예정작의 노출 방식

**선택: A안(2026-10-14).** 요청 연도에 전 세계 최초 공개가 예정되어 있으나 검색 시점에 **실제로 공개되지 않은 영화·신규 시즌**을 정규 TOP 10과 분리된 **`공개 예정작`** 영역에 표시한다.

- 확인된 **예정 공개 연월(가능한 경우 날짜), 예정/확정 상태, 한국 출시·극장 상영 예정 경로(확인된 경우), 출처·조회 시점**을 표시한다. 예정 일정은 바뀔 수 있음을 명시한다.
- 실제 공개 전에는 **P-GSEI를 계산하지 않고, 인기 순위나 점수·가상 평점을 부여하지 않는다.** 홍보량이나 관심도만으로 작품 품질을 추정하지 않는다.
- **`평가 대기 신작`은 이미 공개됐지만 유효 평가 데이터가 부족한 작품**만 포함한다. 두 영역은 혼용하지 않는다.
- 예정작의 실제 공개가 확인되면 **다음 신규 추천 검색부터** 평가 데이터에 따라 정규 TOP 10 또는 `평가 대기 신작`으로 재분류한다. 과거 추천 스냅샷은 변경하지 않는다.
- **D-20 A안 확정:** 공식 발표된 글로벌 예정작은 한국 출시·관람 계획이 확인되지 않아도 `공개 예정작`에 노출하고, `한국 공개 미확인` 표시를 적용한다. 국내 실제 관람 가능 여부와 혼동하지 않는다.

### D-20 (확정): 한국 공개·상영 계획이 확인되지 않은 글로벌 예정작의 노출

**선택: A안(2026-10-14).** 전 세계 첫 공개가 공식 발표된 영화·신규 시즌은 **한국 공개 일정이나 한국 OTT·극장 계획이 아직 확인되지 않았어도 `공개 예정작`에 포함**한다.

- 세계 최초 공개 예정 연월과 한국 공개 예정 연월을 **서로 다른 필드**로 표시한다. 확인되지 않은 날짜는 `미확인`으로 두며 추정하지 않는다.
- 한국 OTT 또는 극장 개봉 정보가 없거나 미확정이라면 반드시 **`한국 공개 미확인`**으로 표시한다. 국내 공개가 확정된 작품은 검증된 예정 플랫폼·극장 정보만 표기한다.
- 공식 제작사·배급사·플랫폼 발표 등 검증 가능한 출처와 조회 시점을 보관한다. 단순 루머나 비공식 예상 일정은 '공식 공개 예정 확인'으로 취급하지 않는다.
- 국내 공개 미확정인 예정작은 **정규 영화·드라마 TOP 10, 기공개 `평가 대기 신작`에 포함하지 않는다.** 모든 미공개 예정작에는 P-GSEI 점수·인기 순위·`한국에서 지금 볼 수 있음` 표시를 부여하지 않는다.
- 예정된 첫 공개가 실제 이루어진 이후에는 다음 신규 검색에서 D-01/D-17의 국내 가용성 기준에 따라 정규 후보 또는 적절한 별도 상태로 분류한다. 한국 시청처가 계속 미확인이면 정규 TOP 10에 넣지 않는다.

### D-21 (확정): 연도 입력이 없는 경우의 기본 공개 연도 범위

**선택: A안(2026-10-14).** 사용자가 공개 연도를 따로 지정하지 않으면 **조회 시점의 현재 연도 포함 최근 3개 연도**에 최초 공개된 영화와 신규 시즌을 기본 검색한다. 예를 들어 2026년에는 **2024~2026년**, 2027년에는 **2025~2027년**이 된다.

- **명시적 연도 우선:** `26년 첩보`처럼 연도가 명시되면 2026년만 적용한다. 이전 확정 D-18의 영화 세계 최초 공개 연도·드라마 시즌 세계 최초 공개 연도 기준을 유지한다.
- **연도 범위 명시:** 추천 화면에 기본 연도 범위를 표시하여 사용자가 검색 조건을 알 수 있게 한다.
- **사용자 확장:** `전체 연도 보기`를 선택하면 연도 조건을 제거하여 과거 명작까지 검색한다. 전체 연도 검색에서도 국내 관람 가능성, 시청 완료 제외, 영화·드라마별 TOP 10 및 P-GSEI 기준은 동일하다.
- **검색 속도·부족 후보 처리(D-22 A안):** 최근 3개 연도 범위를 유지하고 후보가 10개 미만이어도 과거 연도로 자동 확장하지 않는다. `전체 연도 보기`를 사용자가 선택해야만 연도 제한을 해제한다.
- **공개 예정작:** 최근 3개 연도 또는 명시한 연도의 미공개 예정작은 D-19·D-20 기준대로 정규 TOP 10이 아닌 별도 영역에서 처리한다.

### D-22 (확정): 최근 3개 연도 후보가 부족한 경우 자동 확장 여부

**선택: A안(2026-10-14).** 기본 최근 3개 연도에 확인된 추천 후보가 영화 또는 드라마별로 10개 미만이어도 **검증된 작품만 실제 개수대로 표시**하고, 연도를 자동으로 넓히지 않는다.

- **TOP N은 상한:** 영화 TOP 10·드라마 TOP 10은 각 최대 10편·10시리즈이며, 10개를 억지로 채우는 의무가 아니다.
- **범위 유지:** 최근 3개 연도에 7개만 있으면 7개를 출력한다. 명시적 연도가 있으면 해당 연도를 사용자 지시 없이 변경하지 않는다.
- **수동 확장:** `전체 연도 보기`를 사용자가 선택한 경우에만 연도 조건 없이 새 검색을 실행한다. 다른 검색·평가·시청 필터는 유지한다.
- **신작 분리 유지:** 평가 대기 신작 및 공개 예정작은 정규 TOP 10의 빈자리를 채우지 않는다.
- **분야별 독립 처리:** 영화가 10개 미만이어도 드라마의 완료·출력을 지연시키지 않는다(D-16 유지).

### D-23 (확정): 요청한 장르와 인접 장르의 정규 추천 포함 범위

**선택: A안(2026-10-14).** **사용자가 요청한 장르가 주요 소재·갈등·서사의 중심인 작품만 영화/드라마 정규 TOP 10에 포함**한다. 그와 분위기·소재가 비슷하더라도 직접 관련성이 약한 작품은 별도의 **`관련 장르 추천`**에서만 안내한다.

- **직접 관련 예:** `첩보` 요청에서 정보기관의 임무, 스파이 활동, 잠입·이중간첩, 정보전이 핵심 줄거리인 작품. 첩보와 액션/정치 스릴러가 동시에 핵심인 작품도 정규 후보가 될 수 있다.
- **인접 장르 예:** 정보기관 활동이 중심이 아닌 일반 정치 스릴러, 국제 범죄 액션, 경찰 수사물은 인접 장르로 취급한다. 단순 키워드·출연 배우 유사성만으로 직접 관련성을 인정하지 않는다.
- **장르 검증:** 작품 개요·공식 장르 표기·신뢰할 만한 작품 설명 등을 확인한다. 장르 판단 근거가 애매하면 정규 순위에 억지로 넣지 않으며, 검증 가능 정보만 사용자에게 제공한다.
- **정규 순위 보호:** 장르에 직접 부합하는 작품이 10개 미만이더라도 `관련 장르 추천`으로 빈자리를 채우지 않는다. 분야별 TOP 10·한국 관람 가능·연도·시청 완료 제외·P-GSEI 등 기존 필터는 유지한다.
- **속도 보호:** D-24 A안에 따라 `관련 장르 더 보기`를 사용자가 선택했을 때만 관련 장르를 추가 검색한다. 정규 TOP 10을 먼저 확정·출력하며 추가 결과는 기존 순위를 변경하지 않는다.

### D-24 (확정): `관련 장르 추천` 영역의 기본 노출 방식

**선택: A안(2026-10-14).** 정규 영화·드라마 TOP 10을 먼저 출력하고, 사용자가 **`관련 장르 더 보기`**를 눌렀을 때만 인접 장르의 추가 검색·검증을 시작한다.

- **기본 결과:** 관련 장르 추가 검색 없음. 정규 TOP 10과 `관련 장르 더 보기` 버튼만 표시.
- **사용자 선택 시:** 기존 장르에 가까운 후보만 별도로 탐색해 `관련 장르 추천`에 표시하고, 원래 영화/드라마 순위와 카드 상태는 유지.
- **품질·범위 유지:** 원 요청의 공개 연도, 국내 합법 관람 경로, 시청 완료 제외, 출처 검증을 확장 추천에도 적용.
- **성능·비용:** 사용자가 선택하지 않으면 관련 장르 전용 검색/검증 호출을 실행하지 않음. 상세 실행·캐시 정책은 `spec.md`에서 결정.

### D-25 (확정): 영드·유럽 드라마로 확장하는 시점

**선택: A안(2026-10-14).** 기본 미드·영화 추천에는 영드·유럽 드라마를 자동 검색하지 않는다. 사용자가 **`영드·유럽 드라마 더 보기`**를 선택한 때에만 추가 검색한다.

- **초기 결과 우선:** 미국 드라마 TOP 10 및 영화 TOP 10을 먼저 검색·확정한다. 미드 후보가 10개보다 적어도 다른 국가 드라마로 자동 보충하지 않는다.
- **사용자 의도 우선:** `영드 추천`, `유럽 드라마 추천`, `영화 + 영드`처럼 처음부터 영드·유럽을 명시한 경우에는 별도 확장 버튼 없이 요청한 범위를 검색한다.
- **필터 일관성:** 추가 검색에도 공개 연도, 직접 관련 장르, 한국 합법 시청 경로, 시청 기록 제외, 신뢰도·근거 검증을 동일하게 적용한다.
- **실행 속도:** 영드·유럽 드라마 추가 조사로 기본 영화·미드 추천의 첫 응답을 지연시키지 않는다.
- **결과 배치(D-26 A안 확정):** 추가 검색 결과는 기존 미국 드라마 TOP 10에 합치지 않고 별도 `영드·유럽 드라마 TOP 10`으로 표시한다.

### D-26 (확정): 영드·유럽 드라마 추가 검색 결과 표시 방식

**선택: A안(2026-10-14).** 영드·유럽 드라마를 **미국 드라마 TOP 10과 별도인 `영드·유럽 드라마 TOP 10` 섹션**에 최대 10작품까지 표시하고 기존 미국 드라마 순위·카드 상태는 유지한다.

- **독립 순위:** 영드·유럽 드라마끼리 검증된 P-GSEI 기준으로 정렬한다. 미국 드라마와 통합 재산정하지 않는다.
- **사용자 트리거:** `영드·유럽 드라마 더 보기`를 눌렀을 때만 추가 검색한다(D-25). 단, 자연어 요청이 영드·유럽 드라마를 직접 지칭하면 처음부터 해당 분야를 검색·출력한다.
- **기존 검색 보호:** 미국 드라마 TOP 10 및 영화 TOP 10의 작품·순위·시청/찜 표시를 변경하지 않는다. 확장 결과는 독립적으로 `검색 중/완료/실패` 상태를 갖는다.
- **필터 일관성:** 요청 연도, 핵심 장르, 국내 합법 관람 가능 여부, 시청 완료 제외, 출처 검증을 동일 적용한다. 후보가 부족해도 미국 드라마로 빈자리를 채우지 않는다.
- **구체화 위임:** 국가 분류(공동제작 포함), 섹션 ID, 추천 실행과 캐시, 중복 작품 처리 기준은 `spec.md`에서 정의한다.

### D-27 (확정): 사용자별 시청 기록·찜 데이터의 로그인 방식

**선택: A안(2026-10-14).** **Google 계정 OAuth 로그인**을 사용하며, 별도 자체 비밀번호나 이메일 일회용 로그인 링크는 초기 버전에 구현하지 않는다.

- **인증:** Google OAuth/OpenID Connect로 로그인하고 서비스 내부 사용자 계정에 연동한다. Google 비밀번호는 서비스가 직접 받거나 저장하지 않는다.
- **사용자별 데이터:** 시청 완료 영화·시즌, 찜 목록 및 관련 상태는 로그인한 사용자별로 분리하고 인증된 사용자 본인만 접근·변경할 수 있다.
- **PC·모바일 동기화:** 동일 Google 계정으로 로그인하면 동일한 DB 기록을 즉시 조회·수정할 수 있어야 한다. 변경 전·후 UI는 저장 결과에 따라 일관되게 표시한다.
- **세션 보안:** 로그아웃과 인증 만료 이후 보호된 시청·찜 정보 접근을 차단하고, 인증되지 않은 요청이 다른 계정의 데이터를 조회하거나 변경하지 못하도록 한다.
- **권한 최소화:** 로그인에 필요한 최소 권한만 요청하며 Gmail·Google Drive 콘텐츠 등에 대한 접근을 전제로 하지 않는다.
- **확정된 접근 범위(D-28 A안 + D-29 A안):** 본인 및 관리자가 수동 승인한 Google 계정만 이용할 수 있다. 승인·철회는 초기 관리자 UI 없이 운영한다. 인증 세션·접근제어·승인 계정 식별 방법은 `spec.md`에서 명세한다.

### D-28 (확정): 서비스 가입 및 이용 대상

**선택: A안(2026-10-14).** **초기 서비스는 본인 및 사전에 승인된 Google 계정만 사용**할 수 있다. 공개 Google 계정 누구나 가입하는 방식은 초기 범위에서 제외한다.

- Google 로그인 자체의 성공 여부와 **서비스 이용 승인 여부는 분리**한다. 승인되지 않은 계정은 검색·추천·시청 기록·찜 기능을 사용할 수 없다.
- 승인된 사용자마다 시청·찜 기록을 독립 관리하고, 다른 계정의 정보를 조회·변경하지 못하게 한다.
- 비승인 사용자의 요청은 Google Gemini API 호출 전에 차단해 불필요한 비용을 막는다.
- 초기에는 승인 계정 중심으로 운영하되, 데이터 모델·권한 계층은 향후 여러 사용자를 지원하도록 확장 가능하게 설계한다.
- 승인 계정을 실제로 추가·철회하는 운영 방식은 **D-29 A안(관리자 수동 등록·철회)**으로 확정했고, 계정 식별·세션·API 접근제어의 세부 구현은 `spec.md`로 넘긴다.

### D-29 (확정): 승인된 Google 계정의 등록·관리 방식

**선택: A안(2026-10-14).** 관리자가 Google 계정을 **수동으로 등록·철회**하며 초기에는 별도 가입 요청·승인 관리 UI를 개발하지 않는다.

- **운영:** 승인 목록의 생성·갱신·철회는 관리자 전용 운영 수단에서 수행한다. 구체적인 수단(DB 관리·전용 관리 명령 등)은 `spec.md`에서 선정한다.
- **접근 제어:** OAuth 인증 성공 후에도 서버가 승인 여부를 확인한다. 미승인·철회된 계정은 추천 실행과 시청 기록·찜 목록 API에 접근할 수 없다.
- **철회:** 승인 철회는 이후 보호 API 요청부터 반영되도록 한다. 기존 시청 기록·찜 데이터를 자동 삭제한다는 뜻은 아니다.
- **초기 범위 제외:** 앱 내 공개 가입 신청, 승인 요청 대기열, 관리자 승인·거절 화면을 만들지 않는다.
- **확장성:** 사용자·승인 상태를 별도로 모델링하여 다중 사용자 서비스 및 추후 관리 UI 추가를 허용한다.

### D-30 (확정): 검색 결과 캐시 및 최신 정보 다시 검색

**선택: A안(2026-10-14).** 동일한 조건의 **검증 완료된 추천 결과는 최대 24시간** 캐시하여 빠르게 재사용하고, 정보 확인 시점을 화면에 표시한다. 사용자가 **`최신 정보로 다시 검색`**을 선택하면 캐시된 결과만 반복 표시하지 않고 원천 조회·검증을 다시 시도한다.

- **검증된 결과만 캐시:** 임시 미검증 후보·허위 점수·확인되지 않은 링크를 확정 추천으로 재사용하지 않는다. 영화·드라마는 독립 결과 캐시 및 완료 상태를 유지한다(D-16).
- **국내 시청·관람 경로는 별도 검증:** 구독/무료/대여/구매 제공 및 **현재 극장 상영 여부**는 최대 24시간 추천 결과 캐시와 동일한 신선도로 간주하지 않는다. 짧은 갱신 주기와 출처·확인 시점을 별도로 적용한다. 유효성을 확인할 수 없으면 `미확인`으로 표시하고 현재 볼 수 있다고 단정하지 않는다.
- **개인 상태는 캐시하지 않음:** 승인된 사용자 여부, 시청 완료/되돌리기 및 찜 상태는 현행 DB 정보를 적용한다. 다른 사용자 시청 기록이 섞이지 않으며, 시청한 작품은 캐시를 재활용하는 **새 검색에서도 제외**한다.
- **사용자 수동 갱신:** `최신 정보로 다시 검색`의 성공/실패와 갱신 시점을 보여준다. 검색 원천 조회를 새로 수행하더라도 제공처에 새로운 업데이트가 없으면 정보가 실제로 변경되지 않을 수 있다.
- **성능과 신뢰의 균형:** TTL 세부 기준, 캐시 키, 강제 갱신 실패 및 부분 실패 처리, 국내 제공처/영화 상영 정보의 독립 검증 주기 등은 `spec.md`에 정의한다.

### D-31 (확정): 관심 없는 작품을 추천에서 제외

**선택: A안(2026-10-14).** 추천 카드에 **`관심 없음`** 토글을 추가한다. 본 적 없는 작품도 제외할 수 있으며, **`봤음`과는 별개로 기록**한다. 현재 결과 카드와 순위는 유지하고 사용자에게 제외 상태와 `해제`를 보여준다. **다음 신규 검색부터** 정규 추천에서 제외하며, 캐시를 재사용해도 현재 사용자별 제외 기록을 재적용한다.

- **등록·해제:** 추천 결과 카드에서 제외 등록 및 해제를 지원한다. 해제 후 다음 신규 검색에서 다시 추천 후보로 참여할 수 있다.
- **개인 상태 분리:** 다른 계정의 검색에는 영향이 없다. 평가 점수(P-GSEI)는 수정하지 않고 추천 표시 여부만 필터링한다.
- **시청 상태와 구분:** `관심 없음`은 시청 완료를 의미하지 않는다. D-33 A안에 따라 해당 작품의 기존 `찜`을 자동 해제하며, 제외 해제 시 자동 해제된 찜만 조건부 복원한다.
- **적용 범위 확정(D-32 A안):** 드라마 `관심 없음`은 동일 작품의 전체 기존·향후 시즌을 제외하며, 스핀오프 등 별도 작품까지 확장하지 않는다.

### D-32 (확정): 드라마의 `관심 없음` 적용 범위

**선택: A안(2026-10-14).** 추천 시즌에서 `관심 없음`을 누르면 **동일 드라마 시리즈의 모든 기존 시즌과 향후 공개될 시즌**을 추천에서 제외한다. 시즌마다 다시 제외할 필요가 없고, 추천 카드에 설정된 상태는 이후 신규 검색부터 반영한다.

- **적용 단위:** 같은 시리즈에 속한 전체 시즌. 영화·독립 작품은 해당 작품 하나가 기본 제외 단위다.
- **스핀오프 분리:** 스핀오프·프리퀄·후속 별도 시리즈는 같은 세계관이어도 **별도 작품으로 관리**하고, 자동 제외하지 않는다.
- **해제:** 전체 시리즈 제외 설정을 해제하면 다음 신규 검색부터 나머지 검색 조건과 미시청 여부를 만족하는 시즌이 다시 후보가 된다.
- **결과 안정성:** 현재 카드·순위는 변하지 않으며, 사용자별 제외 기록은 재검색·캐시 적중에도 반영한다.
- **후속 설계:** 작품 ID와 시즌 ID 구분, 공식 스핀오프와 동일 작품의 경계는 `spec.md`에서 정의한다.

### D-33 (확정): `관심 없음`과 `찜`의 상태 연동

**선택: A안(2026-10-14).** 추천 카드에서 `관심 없음`을 저장하면 해당 작품에 이미 설정된 **`찜`을 자동 해제**하고 관심 목록에서도 제거한다. `관심 없음`을 해제하면 **그 작업 때문에 자동 해제됐던 원래 찜만 복원**한다.

- **원래 찜이 있을 때:** `찜=true` → `관심 없음` 저장 성공 시 `찜=false` → 제외 해제 시 원래 찜 복원.
- **원래 찜이 없을 때:** `찜=false` → 제외/해제 후에도 `찜=false` 유지. 자동으로 새 찜을 만들지 않는다.
- **후속 수동 선택 존중:** 제외 이후 사용자가 직접 찜을 수정했다면 제외 해제 시 기존 찜 복원 로직으로 최신 수동 상태를 덮어쓰지 않는다.
- **저장 및 실패 처리:** 제외 상태·자동 찜 해제·복원 근거를 사용자별로 일관성 있게 저장하고 부분 성공을 표시하지 않는다. 원자적 저장, 상태 버전 및 충돌 판단은 `spec.md`에서 정의한다.
- **결과 안정성:** D-08·D-31 정책대로 현재 추천 카드와 순위는 유지하고, `관심 없음`의 추천 제외 효과는 다음 신규 검색에서 적용한다. 기존 P-GSEI 자체는 변경하지 않는다.

### D-34 (확정): 시청 완료 후 선택적 개인 별점 및 취향 학습

**선택: A안(2026-10-14).** `봤음` 처리한 영화와 드라마 **시즌**에 **개인 별점 1~5점**을 선택적으로 저장한다.

- **비필수:** `봤음` 저장에 별점을 요구하지 않는다. 별점을 남기지 않는 사용자의 시청 이력도 정상 반영한다.
- **범위:** 영화는 작품별, 드라마는 시즌별로 별점을 저장한다. 한 사용자는 기존 점수를 수정하거나 해제할 수 있다.
- **개인화:** 축적된 별점은 다음 신규 추천의 **P-GSEI 개인 취향 10%**에만 활용한다. **재미·관객 만족도 40%, 대중 인기·화제성 40%, 전문가 평가 10%**는 그대로 유지한다. 서비스가 IMDb 등 외부 평점을 변경·대체하지 않는다.
- **이력이 적을 때:** 별점이 거의 없거나 전혀 없으면 기존에 지정한 취향(첩보/액션, 빠른 전개, 유머·진중한 스릴러 선호)을 기본값으로 사용한다. 지나친 과적합 방지 방식은 `spec.md`에서 정의한다.
- **보안·일관성:** Google 인증 사용자별로 독립 저장·동기화하며 DB 저장 실패를 성공으로 표시하지 않는다. 현재 결과 카드·순위는 그대로 두고 다음 신규 검색부터 학습된 취향을 반영한다.
- **입력 방식 확정(D-35 A안):** `봤음` 저장 후 별점 팝업을 띄우지 않고 카드에서 선택적으로 언제든 등록·수정·해제한다. 시청 완료 되돌리기 시 별점은 D-36 A안에 따라 보존·비활성화하고, 재완료 시 자동 복원한다.

### D-35 (확정): 개인 별점의 카드 내 선택적 입력

**선택: A안(2026-10-14).** `봤음` 저장이 성공하면 **해당 추천 카드에서 `내 별점`(1~5점)을 선택적으로 입력·수정·해제**할 수 있다. 별점 선택 팝업을 띄우거나 입력을 강제하지 않는다.

- **선행 조건:** 영화를 `봤음` 처리하거나 해당 드라마 시즌의 시청 완료가 저장된 뒤에만 별점 UI를 활성화한다.
- **즉시 저장:** 시청 완료 자체는 별점과 독립적으로 즉시 저장한다. 별점을 비워도 추가 조작이 필요하지 않다.
- **선택적 평가:** 현재 추천 카드 안에서 등록·수정·해제를 수행한다. 별점 저장 실패는 성공으로 표시하지 않고 이전 확정 상태를 유지한다.
- **결과 일관성:** 현재 추천 카드와 TOP 10 순위는 유지한다. 개인화 점수 10% 내 반영은 다음 신규 검색부터 적용한다.
- **구현 상세:** 별점 UI 구성, 키보드 접근성, 수정/해제 API, 중복 요청·서버 실패 처리는 `spec.md`에서 정의한다.

### D-36 (확정): `봤음` 되돌리기 후 개인 별점의 보존·복원

**선택: A안(2026-10-14).** 사용자가 영화 또는 드라마 시즌에서 `봤음`을 되돌려도 기존 **1~5점 개인 별점은 삭제하지 않고 보존하되 비활성화**한다. 이후 **동일 영화·시즌**을 다시 시청 완료로 체크하면 저장된 별점을 자동 복원한다.

- **되돌리기:** `봤음=true, 별점=4` → `봤음=false, 별점=4(보존·비활성)`. 추천 카드에는 활성 개인 별점 입력/표시를 하지 않는다.
- **학습 제외:** `봤음=false`인 영화·시즌의 보존 별점은 다음 추천의 개인 취향 점수(10%) 계산에서 제외한다. 개인 별점 보존이 외부 평점이나 40/40/10/10 가중치를 변경하지 않는다.
- **재완료:** 같은 영화·시즌에 다시 `봤음=true`를 저장하면 이전 4점을 자동으로 활성화하여 카드에서 확인·수정·해제할 수 있다. 원래 별점이 없으면 생성하지 않는다.
- **시즌·계정 분리:** 한 시즌의 되돌리기/재완료로 다른 시즌·영화·다른 사용자의 별점을 변경하지 않는다.
- **안전한 저장:** 시청 상태와 별점 활성 여부는 일관되게 저장하고, DB 저장 실패를 완료로 오표시하지 않는다. 이전 찜 상태 복원(D-11 A안)과 함께 상태 일관성을 유지한다.
- **후속 상세:** 별점 활성 여부 표현, 트랜잭션 및 사용자 수동 변경 충돌은 `spec.md`에 정의한다.

### D-37 (확정): Gemini API 검색 사용량 및 비용 제어

**선택: A안(2026-10-14).** 관리자가 정한 **월별 Google Gemini API 예산 상한과 사용자별 유료 검색·호출 한도**를 적용한다. 검색 비용만 기록하는 무제한 사용 방식은 채택하지 않는다.

- **요청 전 차단:** 서버는 승인 계정 여부를 확인한 뒤 새 Google Gemini API 호출에 대한 남은 월 예산·사용자 한도와 예상 사용량을 검토한다. 초과가 예상되면 신규 유료 호출을 시작하지 않고 한도 도달 사유를 알려준다.
- **유료 호출과 무료 조회 구분:** 이미 검증된 추천 캐시만 열람하는 경우와, Gemini API 호출 없이 자신의 시청 기록·찜·관심 없음·개인 별점을 조회/수정하는 경우에는 검색 한도로 차단하지 않는다. 캐시 출력 과정에서 LLM 호출이 필요하다면 해당 호출은 한도에 포함한다.
- **사용량 가시성:** 월별 실제/추정 비용, 사용자별 검색·호출량, 한도 상태를 기록한다. 별도 사용자 간 사용량과 개인 데이터는 분리한다.
- **초기 운영 단순화:** 한도 값은 운영자가 수동 설정하고 초기 관리자 웹 UI를 만들지 않는다(D-29). D-38 A안에 따라 사용자별 검색 한도는 일별, 서비스 전체 예산은 월별로 관리한다. 구체 월 예산 금액·사용자별 일일 횟수·초기화 시각 및 잔액 표시 상세는 `spec.md`에서 정의한다.
- **기술적 한계:** 청구 반영 지연과 동시 호출을 고려해 사전 예약·안전 여유분으로 애플리케이션 측에서 추가 요청을 통제한다. Gemini 플랫폼의 청구 총액이 수학적으로 정확히 상한 아래에서 멈춘다는 보증은 하지 않는다.

### D-38 (확정): 사용자별 일일 검색 한도 + 서비스 전체 월 예산

**선택: A안(2026-10-14).** 승인된 사용자마다 **일일 유료 검색 한도**를 적용하고, 서비스 전체에는 **월별 Google Gemini API 예산 상한**을 함께 적용한다.

- **일일 한도:** 사용자마다 하루 동안 실행 가능한 유료 검색 횟수를 별도로 관리하며 날짜가 바뀌면 초기화한다. 계정 간 검색량을 합산해 한 개인의 일일 할당량을 소진시키지 않는다.
- **월별 예산:** Google Gemini API의 서비스 전체 월 예산은 별도 유지한다. 다음 날 일일 한도가 초기화되더라도 월 예산이 부족하면 새 유료 호출은 차단한다.
- **한도 도달 시:** 요청을 실행하지 않고 일일 횟수/월 예산 중 어느 조건에 걸렸는지 안내한다. 추가 Gemini 호출이 없는 기존 검증 캐시와 개인 시청 기록·찜·관심 없음·별점 조회 및 변경은 계속 허용한다.
- **미세 규칙 이관:** 실제 일일 횟수, 월 예산 금액, 리셋 시각·시간대, 동시 실행 차감·실패 처리 등은 `spec.md`에서 명세한다. 무엇을 유료 검색 1회로 볼지는 D-39에서 결정한다.

### D-39 (확정): 유료 검색 1회 집계 기준

**선택: A안(2026-10-14).** **사용자가 실행한 신규 유료 검색 요청 1건을 1회**로 집계한다. 내부 에이전트가 영화·드라마를 병렬 검색하거나 Google Gemini API를 여러 차례 호출하더라도 사용자 일일 검색 횟수는 요청 단위로 차감한다.

- **기본 통합 요청:** `2026년 첩보 영화와 미드 추천` 요청 1건으로 영화 TOP 10과 드라마 TOP 10을 생성하면 **1회** 차감.
- **사용자 요청에 따른 추가 검색:** `최신 정보로 다시 검색`, `전체 연도 보기`, `관련 장르 더 보기`, `영드·유럽 드라마 더 보기` 등은 **실제로 새 유료 검색이 발생할 때마다 각각 1회** 차감.
- **무료 캐시 조회:** 추가 Google Gemini API 호출 없이 기존 검증 캐시·추천 결과를 재열람하는 경우 **0회** 차감. 캐시 화면에서라도 신규 Gemini API 호출이 발생하면 이를 숨겨서 무료 조회로 표시하지 않는다.
- **별도 비용 추적:** 1회의 사용자 검색에 포함된 모든 Google Gemini API 호출·토큰·추정/실제 비용은 월 예산 관리에 각각 기록한다. **검색 횟수 1회가 API 호출 1번을 뜻하지 않는다.**
- **후속 명세:** 차감 확정 시점, 시작 전 실패·취소, 실행 중 중단, 분야별 부분 실패, 동시 중복 요청 방지 및 환급 정책은 `spec.md`에서 정의한다.

### D-40 (확정): 작품 상세 무료 조회 + 선택형 AI 추가 분석

**선택: A안(2026-10-14).** 저장된 시즌 정보·평점 추세·스핀오프·검증된 유튜브 링크 등 **Google Gemini API 신규 호출 없는 작품 상세 조회는 0회**로 집계한다. 사용자가 추가 심층 분석을 요청하지 않는 한 AI 분석은 자동 실행되지 않는다.

- **선택 실행:** 사용자에게 `AI 상세 분석` 실행을 명시적으로 제공하고, 새 Google Gemini API 호출이 필요한 분석을 선택한 경우에만 **유료 요청 1건당 1회** 차감한다.
- **사전 고지 및 한도 검증:** 사용자 일일 잔여 유료 횟수와 서비스 전체 월 예산을 분석 실행 전에 확인하고, 유료 요청임을 인지할 수 있도록 표시한다.
- **무료 조회 유지:** 일일 검색 횟수 또는 월 예산이 소진되어도 Google Gemini API 호출이 없는 기존 상세 결과는 계속 열람할 수 있다.
- **후속 상세:** 분석 결과 캐시 정책과 같은 분석을 다시 보는 경우의 비용 집계, 중복 요청·취소·실패·부분 결과 처리는 `spec.md` 및 후속 결정에서 정의한다.

### D-41 (확정): 승인 사용자 간 공통 작품 캐시 재사용

**선택: A안(2026-10-14).** 공개된 작품 정보(평점·시즌·OTT·스핀오프 등) 및 개인정보가 들어 있지 않은 **비개인화 AI 분석 결과**는 승인 사용자 간 공통 캐시로 공유한다. 시청 기록·찜·관심 없음·별점·취향·최종 개인화 추천 결과는 사용자별로 분리한다.

- **데이터 경계:** 공통 캐시에 사용자 식별 정보·개인 프롬프트·개인화 점수/결과를 포함하지 않는다. 비개인화 여부가 불명확한 분석은 사용자별로 격리한다.
- **접근 통제:** 공유 캐시 이용자도 Google OAuth 인증과 승인 계정 인가를 반드시 통과해야 한다.
- **점수·필터:** 동일 작품 정보로 시작하더라도 `봤음`·`관심 없음` 제외 및 P-GSEI 계산은 각자의 데이터로 다시 수행한다. 사용자 간 최종 추천 스냅샷은 공유하지 않는다.
- **최신성:** 기존 최대 24시간 추천 캐시와 국내 OTT·극장 정보의 별도 검증 원칙을 유지한다. 오래된 경로를 확정으로 보이지 않는다.
- **비용:** 다른 사용자가 생성한 공통 캐시라도 유효하고 Google Gemini API 신규 호출이 없으면 무료(0회)이다. 내부 호출이 새로 발생하면 D-39·D-40의 한도 규칙을 따른다.
- **후속 명세:** 공통/개인 캐시 키, 개인 데이터 섞임 방지, 계정 철회와 접근 제어, 공통 데이터 갱신 충돌, 제공자 라이선스 준수는 `spec.md`에서 정의한다.

### D-42 (확정): 외부 평가·시청처 데이터 일부 조회 실패 시 처리

**선택: A안(권장·사용자 일괄 위임, 2026-10-14).** 일부 외부 공급자가 지연·실패해도 한국 관람 경로·실제 공개 연도·직접 장르 적합성이 검증된 작품만 우선 평가·출력한다. 평점 등 누락 항목은 `미확인`으로 표시하며 점수 자체를 만들지 않는다. 검증 후보가 부족해도 숫자를 채우지 않으며, 끝난 영화/드라마 분야는 다른 분야의 실패 때문에 취소하지 않는다. 추가 자동 무한 재시도는 하지 않는다.

### D-43 (확정): 조건 충족 결과가 없거나 부족할 때

**선택: A안(권장·일괄 위임).** 현재 적용된 연도·핵심 장르·국내 관람 가능·미시청 등의 조건과 결과 부족 이유를 간략히 안내한다. `전체 연도 보기`, `관련 장르 더 보기`, `영드·유럽 드라마 더 보기`는 **사용자 선택 시에만** 별도 검색을 수행한다. 기존 D-22~D-26의 자동 확장 금지 정책 유지.

### D-44 (확정): 동명이작·시즌 등 중복 식별

**선택: A안(권장·일괄 위임).** 원제, 첫 공개 연도, 검증된 작품/시즌 ID를 활용해 영화·드라마·리메이크·시즌을 정확히 분리한다. 확인되지 않은 일치를 LLM 추측으로 병합하지 않으며, 정규 TOP 10에서는 보류한다.

### D-45 (확정): 작품별 시청·예매 링크 검증 실패

**선택: A안(권장·일괄 위임).** 작품별로 확인된 국내 구독·무료·대여·구매·영화 예매 URL만 바로가기로 표시한다. 오래되거나 불명확한 링크는 `확인 필요`로 표시하고, 검증된 국내 관람 경로가 하나도 없는 작품은 정규 TOP 10에서 제외한다. D-20의 글로벌 `공개 예정작` 예외와 혼동하지 않는다.

### D-46 (확정): 한국어 유튜브 줄거리 요약이 없을 때

**선택: A안(권장·일괄 위임).** `한국어 요약 영상 미확인` 표시와 함께 검증된 공식 예고편을 보조로 제공할 수 있다. 영상 검색 실패는 추천 순위와 시청 가능 여부에 영향을 주지 않으며, 스포일러 가림(D-02)과 영상 실존 링크 검증을 유지한다.

### D-47 (확정): 비슷한 복합 평가 점수의 표현

**선택: A안(권장·일괄 위임).** P-GSEI 순위를 제공하되 경미한 점수 차이를 과장하지 않고 신뢰도·출처·평가 표본·조회일을 함께 표시한다. 표시 정밀도와 동률 해소의 결정적 규칙은 `spec.md`에서 구현 및 테스트한다.

### D-48 (확정): 길어진 검색의 취소와 완료 결과 보존

**선택: A안(권장·일괄 위임).** 아직 검증 완료되지 않은 검색 분야만 선택 취소할 수 있게 하며, 이미 완료된 분야의 목록·순위·사용자 상태는 보존한다. 취소 타이밍에 따라 이미 발생한 API 비용이 있을 수 있으므로 유료 횟수 정산 규칙을 명세한다. 구현 우선순위는 P1.

### D-49 (확정): 개인 시청 데이터 내보내기·삭제

**선택: A안(권장·일괄 위임).** 본인에게 개인 시청 이력·찜·관심 없음·별점·취향의 내보내기와 삭제 요청 경로를 제공한다. 제3자 열람을 차단하고, 파괴적 삭제 전 확인과 법적·운영상 보존 대상 고지 등을 `spec.md`에 위임한다. 구현 우선순위는 P1(최소한의 삭제 요청 경로는 P0).

### D-50 (확정): 추천 결과 공유와 개인정보 보호

**선택: A안(권장·일괄 위임).** 초기 버전은 개인 추천 링크 공개 공유를 제외한다. 향후 공개 작품 목록만 공유할 수 있도록 설계하고, 시청·찜·관심 없음·별점·취향·검색 비용 등 개인 데이터는 URL과 공유 응답에 포함하지 않는다. 구현 우선순위 P2.

### Intent 동결 판단

**D-01~D-50의 제품 수준 의사결정 완료.** 사용자가 앞으로의 보완 질문에서 권장안을 일괄 채택하도록 위임했으므로, 더 이상 반복되는 A/B 질문으로 중단하지 않는다. 새로 필요한 **구체적 수치·사용 기술·공급자 계약/요금·DB/API 명세·개발 일정은 `spec.md` 및 `plan.md`에서 기본 권장값을 제시**하되, 기존 확정 의도와 충돌하는 변경만 별도 결정으로 기록한다.

### 이후 조정 가능 항목 — 현재는 제안 기본값
- 미시청은 `unknown`과 구분하며, 기본 추천에는 `unknown`도 포함할 수 있다.
- 한국어 자막·더빙, 요약 영상 게시일·길이 등은 검증 가능 시 제공한다.
