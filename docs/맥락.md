## 1. 프로젝트 정의

**Screen Intelligence Agent**는 사용자의 자연어 질문을 받아 미국 드라마(미드)와 영화를 우선적으로 검색하고, 사용자가 명시적으로 요청하거나 수동으로 클릭할 때 영국·유럽 드라마로 확장하여 **검증 가능한 평점·실제 인기·개인 취향·시청 이력**을 종합한 추천 결과를 제시하는 개인 OTT/콘텐츠 탐색 에이전트 서비스다.

- **입력 예:** `2026년 첩보 관련 미드나 영화 추천해줘.`
- **핵심 출력:**
  1. **영화 TOP 10 및 미국 드라마 TOP 10의 독립 섹션 분리 제공** (혼합 순위 금지, `D-05`, `D-26`)
  2. 작품별 제공 플랫폼(국내 OTT 구독·무료·대여·구매 및 **현재 국내 극장 상영작** 포함, `D-17`)
  3. 세계 최초 공개 연도 및 한국 개봉/공개 연도, 종합 개인화 지수 `P-GSEI (40/40/10/10)` 및 구성 근거
  4. 시즌별 공개 연월, 시즌 품질 추세(상승/하락/유지), 안전한 줄거리 맥락(스포일러 차단)
  5. 스핀오프·프리퀄·후속작의 최초 공개 연도 및 시청 순서 관계도
  6. **한국어 전체 줄거리 요약 영상 링크** (스포일러 방지를 위한 사전 잠금 및 명시적 열람 동의, `D-02~D-04`)
- **제품 형태:** Next.js (JavaScript/JSX + Tailwind CSS v4) 웹앱 + FastAPI 독립 백엔드 REST/SSE API (`CR-FE-001`, `SP-01`)
- **LLM 및 결정적 원칙:** Google Gemini API (Gemini 2.5 Flash / Pro, google-genai SDK) 사용. 단, 검색 데이터 자체, 한국 관람 가능 여부, 정량 점수(P-GSEI)는 LLM이 임의로 창작하지 않으며 순수 Python 결정적 코드로 산출 (`agents.md`)

### 제품 한 문장 정의

> **“재미있고 화제가 된 작품을, 내가 아직 보지 않은 시즌까지 포함하여, 신뢰할 수 있는 이유와 함께 빠르게 추천해 주는 개인 OTT 탐색 에이전트.”**

## 2. 해결하려는 문제

현재 콘텐츠 탐색은 여러 OTT, 평가 사이트, 시즌별 공개 정보, 시청 기록이 분산되어 있어 다음 문제가 있다.

1. OTT마다 작품 목록과 제공 국가가 달라 전체 후보를 한눈에 비교하기 어렵다.
2. IMDb 등 단일 평가 지표만으로는 **관객 만족도와 현재의 화제성**을 동시에 판단하기 어렵다.
3. 이전에 본 작품이 추천에 반복되며, 드라마의 **시즌별 시청 진도**가 고려되지 않는다.
4. 전체 시리즈 평점이 높더라도 특정 신규 시즌의 품질 저하를 알기 어렵다.
5. 스핀오프·프리퀄의 공개 순서와 연결 관계, 스포일러 없는 배경을 함께 확인하기 어렵다.
6. 유튜브에서 작품 요약을 찾다가 의도치 않게 결말 스포일러를 당하는 경우가 빈번하다.
7. 검색 과정이 과도하게 다단계이면 첫 추천 결과가 늦게 나온다.

## 3. 사용자·이용 맥락

### 초기 사용자 및 보안 경계

- **이용 대상:** 개인 사용자 중심이되, **Google OAuth + 관리자 승인(Allowlist)**을 통과한 승인된 사용자만 접근 허용 (`D-27~D-29`, `INT-31~33`).
- **개인 취향:** 재미·관객 만족도와 대중적 인기·화제성이 최우선이다.
- **선호 장르·전개:** 첩보·액션, 빠른 전개, 과하지 않은 코미디, 진중한 스릴러.
- **회피 요소:** 지나치게 느린 전개.
- **이용 지역:** 기본값 `대한민국 (KR)`; 작품 원공개 플랫폼과 한국에서 볼 수 있는 플랫폼을 엄격히 구별한다.
- **사용 기기:** PC와 스마트폰의 웹 브라우저 (반응형 웹).

### 대표 사용자 시나리오

1. 사용자가 `2026년 첩보 관련 미드나 영화 추천해줘`라고 입력한다.
2. 시스템은 `2026년`을 **세계 최초 공개 연도 조건**으로 해석한다. (연도 미지정 시 Asia/Seoul 기준 최근 3개년 자동 적용, `D-21`)
3. `첩보`처럼 상위 장르만 제시되면 **세부 장르 선택지 최대 4개**를 한 번 제시한다. (구체적 질의면 즉시 실행, `D-22`)
4. 사용자는 하나 또는 여러 세부 장르를 선택하거나 `전체`로 진행한다.
5. 시스템은 **영화(MOVIE)와 미국 드라마(US_SERIES)를 병렬로 독립 검색**한다. 기준 후보가 부족하더라도 **영드·유럽 드라마로 자동 확장하지 않으며**, 사용자가 명시적으로 확장 요청하거나 클릭할 때만 별도 섹션으로 제공한다 (`D-25`).
6. 이미 시청 완료한 영화와 시즌은 추천 후보에서 제외하되, 새로운 미시청 시즌이 있는 시리즈는 유지한다.
7. 검증된 자료로 개인화 복합 점수(P-GSEI)를 계산하고 높은 순서로 정렬하여 먼저 완료된 섹션부터 SSE로 스트리밍 표시한다.
8. 결과에서 `봤음/안 봤음/찜`을 변경하면 **현재 추천 결과 카드와 순위 스냅샷은 그대로 불변 보존**되고 배지만 오버레이되며, **다음 신규 검색부터 제외**된다 (`D-08`).
9. 작품 카드를 펼치면 시즌별 공개 연월·평점 추세·안전한 줄거리 맥락·관련 스핀오프를 볼 수 있다.
10. 유튜브 요약 영상을 원할 경우, **스포일러 사전 잠금 상태**에서 사용자가 명시적으로 열람 동의를 클릭했을 때 한국어 줄거리 요약 영상을 제공한다 (`D-02~D-04`).

## 5. 개인화 복합 지수: P-GSEI (40/40/10/10)

### 확정 합성식 및 가중치

$$P\text{-}GSEI = 0.40 \times \text{Audience} + 0.40 \times \text{Popularity} + 0.10 \times \text{Critics} + 0.10 \times \text{Taste}$$

| 항목 | 가중치 | 해석 및 출처 |
|---|---:|---|
| 재미·관객 만족도 (A) | **40%** | IMDb, Rotten Tomatoes 관객 평가, TMDB 등 관객 중심 신호 (베이지안 표본 보정) |
| 대중 인기·화제성 (P) | **40%** | 확인 가능한 스트리밍 순위, 관심도, 박스오피스 시청·흥행 지표 |
| 전문가 평가·작품성 (C) | **10%** | Metacritic, Rotten Tomatoes 평론가 평가 등 |
| 개인 취향 적합도 (T) | **10%** | 첩보/액션, 전개 속도, 진중한 스릴러 성향 매칭 및 개인 별점 피드백 반영 |
| **합계** | **100%** | 기본 개인화 지표 `P-GSEI` |

- 각 하위 점수는 **0~100 범위로 정규화**하며, 순수 Python 함수(`backend/app/core/scoring.py`)로 계산한다.
- 특정 축이 결측된 경우 임의의 기본값/0점을 넣지 않고, **관측된 축의 가중치 합으로 재정규화**하며 데이터 신뢰도(Confidence)와 Coverage를 함께 표시한다.
- 평가 표본이 아예 없는 신작은 `P-GSEI`를 계산하지 않고 `AWAITING_RATING` 영역에 별도 배치한다 (`D-14`).

## 6. 시청 기록과 추천 제외의 의미

**단일 Boolean만 사용하지 않는다.** 기본 상태 머신:
- `unknown`: 시청 여부 미확인
- `not_watched`: 미시청
- `watching`: 시청 중
- `watched`: 시청 완료
- `dropped`: 중도 포기
- `not_interested`: 관심 없음 (드라마의 경우 전체 시리즈 일괄 적용, `D-32`)

**원자적 규칙 및 스냅샷 보존 (`D-08`, `SP-06`):**
1. **영화:** 작품 단위 시청 상태 관리.
2. **드라마:** **시즌별 상태가 기본**이며, 전체 시즌을 시청해야 작품 전체가 `watched`로 간주된다. 이전 시즌을 보았더라도 **신규 미시청 시즌이 있으면 추천 후보에 포함**된다.
3. **스냅샷 불변 원칙:** 추천 결과 화면에서 `봤음`을 체크하더라도 현재 화면에서 카드가 사라지거나 순위가 바뀌지 않으며, 시청 완료 배지만 오버레이된다. 해당 작품은 **다음 신규 검색부터 제외**된다.
4. **되돌리기(Undo):** `봤음`을 되돌리면 기존에 자동 해제되었던 `찜` 및 `개인 별점`이 원래 상태로 완전 복원된다 (`D-11`, `D-36`).

## 7. 결과에 반드시 포함할 정보

### 7.1 첫 화면 — 독립 섹션 빠른 목록
1. **영화 TOP 10 / 미국 드라마 TOP 10 독립 분리 섹션**
2. 순위 / 포스터(허가된 경우) / 한글 제목·원제 / 제작국
3. **세계 최초 공개 연도** 및 드라마의 경우 해당 추천 시즌 번호/연월
4. `P-GSEI` 총점(0~100) 및 세부 점수(A/P/C/T), 데이터 신뢰도 배지 (High/Medium/Low)
5. 국내 시청 플랫폼 (OTT 구독/무료/대여/구매 및 극장 상영 링크, 확인 시점)
6. 한국어 자막/더빙 지원 여부 (`지원/미지원/미확인`, `D-04`)
7. 안전한 추천 이유 및 한 줄 줄거리 (스포일러 차단)
8. 시청 상태 UI: `봤음`, `찜`, `관심 없음`, `별점(봤음 후)`

### 7.2 작품 상세 — 클릭 시 지연 확장 (Lazy Loading)
- **시즌별 타임라인:** 시즌별 공개 연월, 시즌별 평점 및 평가자 수.
- **시즌 품질 추세 차트:** 동일 출처 지표 기반 연속 시즌 비교 ($+5$점 이상 상승, $-5$점 이하 하락, 유지).
- **프랜차이즈 관계도:** 원작, 스핀오프, 프리퀄, 시퀄, 후속작의 **세계 최초 공개 연도** 및 권장 시청 순서.
- **YouTube 한국어 줄거리 요약 영상:** 초기 스포일러 잠금 상태 제공 $\to$ 사용자 열람 승인 시 실제 영상 노출. (한국어 요약 부재 시 공식 예고편 대체, `D-46`)

## 8. OTT 검색 범위와 데이터 경계

**조사 대상:** Netflix, Prime Video, Apple TV, Disney+, Paramount+, HBO Max, Hulu, Peacock, 티빙, 웨이브, 왓챠, 쿠팡플레이 및 국내 주요 극장(CGV, 롯데시네마, 메가박스 등).
- **원공개 플랫폼**과 **현재 한국 제공 플랫폼**을 명확히 구분한다.
- 극장 개봉작의 경우 영화관입장권통합전산망(KOBIS) 및 공식 예매 링크를 연동한다.
- 허가된 API 및 제휴 데이터를 사용하며, 무단 스크래핑은 일절 금지한다 (`SP-03`).
- **로컬 개발 및 CI 환경:** 외부 유료/제휴 키가 없어도 개발과 테스트가 가능하도록 **Mock Provider 및 로컬 JSON Fixture 체계**를 완비한다 (`agents.md`, `spec.md`).

## 9. 간결한 실행 흐름과 Multi-Node 오케스트레이션

**원칙: 무거운 순차 에이전트 체인을 지양하고, LangGraph 기반의 경량 4단계 파이프라인으로 처리한다.**

```text
[1. 입력 해석 (Rule Parser 우선 -> Google Gemini Structured Outputs Fallback)]
               ↓
[2. 후보 발굴 + 병렬 섹션 분기 (영화 MOVIE / 미드 US_SERIES Fork)]
               ↓
[3. 검증 + 시청 필터링 + 순수 Python P-GSEI 계산]
               ↓
[4. 섹션별 선완료 SSE 스트리밍 발행]
               └── 사용자 카드 클릭 시에만
                    [지연 로딩: 시즌 추세 + 프랜차이즈 + YouTube 요약(스포일러 잠금)]
```

- **규칙 우선:** 단순 연도/장르 검색은 정규식으로 처리하여 LLM 호출 0회 달성.
- **병렬 분기:** 영화와 미드는 독립적으로 수집·계산되어 먼저 완료된 섹션부터 사용자 브라우저에 표시.
- **비용 가드:** Gemini API 실호출 전 반드시 2단계 원장 예약(Reservation)을 통과해야 함 (`TASK-035`).

## 11. 초기 범위(MVP)와 제외 범위

- Google OAuth + 승인 계정 Allowlist 로그인.
- 자연어 연도/장르 파싱 (세부 장르 최대 4개 제안).

- 현재 한국 극장 상영작 및 국내 OTT(구독/무료/대여/구매) 가용성 검증.

- 사용자 시청/찜/관심없음/별점 상태 머신 (현재 스냅샷 보존, 새 검색부터 제외, Undo 복원).
- 작품 상세 지연 로딩: 시즌 품질 추세 차트, 프랜차이즈 공개연도 관계도.
- YouTube 한국어 요약 영상 (스포일러 잠금 및 명시적 Reveal).
- 일일 10회 / 월 $30 비용 원장 및 일일 사용량 조회 화면.
- Mock Provider 기반 무의존 로컬 실행 및 자동화 테스트 통과.
